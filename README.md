## 2.75.14 这一轮更新了什么（2.75.10 以来的汇总）


谢谢大家发来的一大批样本，维修兔照着学会了好几种新修法！

**修了发来的待修样本**

- 字叠在一起：手机上两页叠成上下两页、上面那页能滑着看的面（翻开的日记本这类），点开批注以后字多了，有时第一段和第二段会叠在同一处。现在不会了；已经叠着的，重新打开这条消息就好。
- 字叠在一起：滑开、刮开式的盖子（盖着底下一页秘密的那种），盖子有时是透明的，盖子上的字和底下的字叠在一起。现在盖子会照原来写的颜色盖住底下，滑开才露出来。
- 一排选项写成单选框、点了内容不换的那种面（几个按钮切换几段字）：现在点哪个出哪段。
- 一颗旋钮、拨杆里藏着两三个选项的：以前点了不动，现在点一下换到下一项，到最后一项再回第一项。
- 一列能上移下移的评论里，有一条自己还能连着点赞的：以前这一条的上移下移按了不动，别的条挪的时候也会跳过它；现在都能挪。
- 一层套一层的步骤折叠（第一步里套着第二步……）：打开第二步时标题不见了、点说明就收起来，现在照普通折叠用。已经这样的，打开外面那一步就好。
- 一排页签、卡片点了看不出选中了谁的：给选中的那个描一圈。
- 签筒、盒子这类点了要弹出结果的（模型写的小程序被酒馆删了）：点了出结果，结果上的「×」点了收回去。
- 模型偶尔把整面写成带反斜杠的样子（字里露出一个个「\n」、样式全没了）：现在会自动还原。
- 副 API 只回了一个「结束」标记、一个字都没有时，报错说清楚是服务商那边没给东西，不再说成兔子镜没认出来。

**生图**

- 生图：两个人以上的图里，一个人的龙角、龙尾这类物种特征被错安到另一个人身上时，会自动去掉（比如兽人角色被安上了 char 的龙角）；各人自己的照旧画。以前已经被错记成她的，也会自动忘掉。

## 2.75.2 这一轮更新了什么（2.74.0 以来的汇总）

```rabbit-bow
      (\(\
      ( -.-)    ……鞠躬
    o_(")(")       谢谢大家！
```

修了发来的待修样本，感谢！

**新功能**

- 问卷兔：「工具 › 第一次使用兔子镜」最上面多了一行「跟随你的喜好一键配置」。问卷兔一题一题问你想怎么玩，每题都有大白话说明，不懂的选「推荐」就行；跟你的选择无关的题会自动跳过。
- 开头先说清楚哪些东西要你自己准备（副 API、生图插件、母本库、世界书……），配好的打勾。做到某一题发现没配好，可以直接点「去配置」，配完点底下的「回到向导」接着做，答案都还在。
- 抽签可以选「抽到哪张用哪张」，也可以先抽几张、让 AI 按这一轮正文的气氛挑一张；选了按正文挑，再拖滑块定贴着正文写的占多少。
- 最后看一眼小结，想改哪条点哪条；点「就这样！」一次配好，没动过的题不会改你原来的设置。原来的设置会先存一份，反悔了在小结页点「恢复到上次配置之前」。
- 新装兔子镜的人，第一次打开设置时会问一句要不要问卷兔帮忙。

**更好用**

- 设置里跟你现在的生成方式无关的选项不再显示（比如跟着正文写时，不再列出副 API 才用得上的那几项），设置本身原样留着。
- 标签过滤里会标出正文所在的那个标签（通常是 content），勾上时提醒一句，免得把正文过滤掉。
- 设置开着时，兔子小窗的提示以前会被设置盖住看不见，现在显示在设置上面。
- 插图的「打开原图」改成「看大图」：就在页面上打开，长按可以保存，不再开新窗口。

**修好的毛病**

- 云酒馆这类要登录的酒馆在 iPhone 上：面里的链接点了不再离开页面；加到主屏幕打开时，「存成长图」「另存打码图」不再走下载（以前会离开酒馆、回来要重新登录），改成分享或长按图片保存。
- 横着滑的一排图上面整块盖着一层「点一下点赞」的：手指放在图上左右划也能滑到下一张了，这一划不会带着整条回复左右翻，也不算点了赞。
- 几张照片各对应一段说明的：点哪张出哪张的说明，换一张就换过去，再点一下收起。
- 翻页旁边的「随机」会随机翻到别的页了；在第一页时「上一页」也不再被当成坏的。
- 开关、选项一开始的状态写在外面一层的（比如弹幕的开关和多少）：开关能关上了，选「少」弹幕就真的变少。
- 一根滑杆调字体粗细的那种：拖动时字跟着变粗变细，旁边的数字也跟着变。
- 多选一的面，选择按钮没写出来（回复被截断在半截）：底下补一排小按钮，能选了，几段内容不再全挤在一起。
- 手机上一排会自动换行的东西（比如几条状态栏）不再被挤出面外、切掉一截。
- 卡片正面「翻过去」、背面「翻回来」的，背面那颗也能翻回来了。
- 维修兔：盖章、弹窗里的「关上」这类不再误报「按了没反应」；滑杆调的样子本来就写坏了、拖了也不会变的，也不再报。
- 优化了 UI。

**更省电、更顺**

- 长倒计时的面挂在屏幕上时，放着不动也一直在忙的那部分活少了八成；还去掉了一处聊天里每出一个字都要跑一次的检查，长聊天更省电。
- 手机上开着键盘打字（比如打拼音，候选栏一会儿多一行、一会儿少一行），兔子镜不再跟着把整个聊天重新排一遍。
- 重说时状态条下面的进度不再一闪一闪，重说进行中打字也更顺；把那一楼滑走再滑回来，「正在重新生成」的提示和进度还在。第一次生成时，进度卡也不会被重画一遍。

**本机存储**

- 在酒馆里删掉聊天时，这台设备上这个聊天的兔子镜备份一起删掉；「清理兔子镜的本机存储」里点「统计所有聊天」，也能找出以前删掉的聊天留下的备份，确认后清掉。
- 以前怎么都清不掉的旧副本，会自动搬进浏览器的版本存档（不占那 5MB，在「兔子镜历史」里还能翻到）；搬不了的单独列出来，自己勾了才清。
- 待修样本箱最多占 0.5MB（以前 2MB），攒满了会问你要不要发给作者、发完删掉。
- 「清理兔子镜的本机存储」那一页的说明改得更短、更好懂。

**修好的毛病**

- 插图被挤得看不见（比如放在翻过来看的卡片正面、写死了高度的屏幕里）：图框不再被挤扁。
- 翻过来看的卡片，翻着的时候存下来，下次打开那一面不再一直藏着。
- 多人卡抽到性转时，问「转谁」的窗口里列的是正文里的人，不会再把卡名当成一个人。
- 按钮在一处、内容在另一处的「点一下看看」（比如点星图上的星星，下面换一张记录卡），点了会跟着换，一次只看一张。
- 维修兔：补不出来时说清楚缺的是按钮、还是按了要变的那一块、还是它不认识的写法；铺在图上的「抹一下」也会去试；报告里不再出现「button」「div」这种词；补测完开关以后，别的结果不会被盖掉。
- 优化了 UI。

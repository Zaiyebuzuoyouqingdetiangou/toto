## 安装与更新

安装通道以包内 manifest 为准。官方仓库为：

```text
https://github.com/Zaiyebuzuoyouqingdetiangou/toto
```

已有安装保持原安装目录，先保留原文件备份。

ZIP 安装：覆盖现有兔子镜扩展目录后完整刷新或重启宿主，确认运行版本为 **1.6**。不要再套一层文件夹，也不要同时启用两份兔子镜。无需清除站点数据、删除成品或重新导入母本。设置入口为扩展魔杖菜单中的「兔子镜」对话框。回看已收藏成品：标题旁星标收藏，设置首页「兔子镜收藏夹」，或工具菜单「打开收藏夹」。

本候选附带 `tests/` 与 `tools/verify_quota_fix.py`，这些文件不会被插件入口执行。

设置顶部「检查并更新」走宿主已经登记的 git remote；新安装应指向官方仓库 `https://github.com/Zaiyebuzuoyouqingdetiangou/toto`。成功后由你手动刷新；权限不足、非 Git 解压安装、宿主不支持接口或仓库网络故障时不能强行更新，也不会删除重装。

“新手指引”默认折叠，首次打开才加载。分别提供跟随正文 API 与独立 API 流程，均先开启自动注入；独立流程包含连接、模型、读取层数与标签过滤。切换帮助页不会切换真实生成模式。

功能说明分六类、44 项，另有醒目的文字导入、文件导入与整库换设备快捷指引。点击名称只定位设置，并可返回原阅读位置。重说、维修等需要选择具体镜面的工具只说明入口；查看指引不会替你导入、开启抽签、执行更新或保存设置。

最低宿主版本标识为 1.13.0；连接配置复用使用的 Connection Manager 接口要求 1.18.0 或以上，旧宿主可使用手动配置的兼容独立接口。不同云酒馆和移动浏览器仍可能存在兼容差异。

## 主要功能

- 普通单面或 2～5 面生成，每面有独立标题、内容、交互和维修入口。
- 跟随正文 API 或独立 API，内嵌和外置显示设置。
- 增强视觉绘制、动态视觉、个性化视觉提示词。
- 纯文字粘贴、TXT / MD / JSON／酒馆世界书母本导入、分类管理、按需抽取与整库导出／导入。
- 🚫 禁词与文字替换：处理兔子镜可见文字，不额外加入模型 Prompt。
- 维修兔、本地交互恢复、挨打猫反馈、标题星标收藏、按角色卡分组的兔子镜收藏夹、抽签收藏和黑名单。

多面共用一次生成请求，但增加面数可能增加输出长度、耗时和费用。独立 API 本轮若没有可用鲜兔镜，会按设置的自动重 roll 次数再发（默认 2）；仍失败则需手动重试。同一面成功重说最多保留 5 版。已有可用面不会被自动重 roll 冲掉。维修只处理已有内容，不能补写截断剧情或空响应。

# 兔子镜小剧场 1.67.45

## 更新日志模块

新增了更新日志板块，感谢 @nancyindaeyo 的更新。

## 本次变动

- 出题规则整体梳理了一遍，一件事只在一处说，「展现形式落地」仍然排在所有规则最前面，内容不变：
  - 去掉互相打架的：选了柔和浅色或深色时，不再同时发「色彩组织」里“非深色模式也可有浓郁主体、彩色承载面与局部深色”那一条（这就是柔和浅色下还出浓色、米黄的原因之一）；「全局视觉地板」里“必须画出远近三层、遮挡与投影”改成只对图形、装置、场景类要求，书信、日志、论坛这类文字媒介以正文和版式为本体，不再被要求做成立体装置。
  - 合并重复的：“对象→操作→状态→反馈”“按钮都要能用、不写 disabled”“触屏优先”“能切回”“不写脚本”这些原来各说了两到五遍，现在各只说一遍；短锁里「认得出」「结果位置」并进了「HTML 共用短检」和「用得出」。
  - 整体设计候选那一大段改成分条，disabled 和“高亮落在按下的按钮上”两条放进硬性要求里，不再藏在长段落中间。
  - 固定规则大约少了五六百字；美化和交互的要求一条没减，只是不再重复。
- 外置库加了「编号 + 标题」的轻量索引，和内置库一样：列目录、选范围只读索引，抽中以后才去读那一条的正文。逐面抽取面板、收藏图鉴草稿打开外置库目录时不再一页一页从头读整库，几千条的库也很快，也不会再因为条目超过两万多条报错。旧库的索引还没有标题时，会顺序读一遍补出目录（只读一遍，不留正文）；重新导入或重建索引后就直接用索引。
- 收藏图鉴「按名称生成草稿」只发简短编号和标题（主题 t1、t2…，展现形式 f1、f2…），不再发外置条目那串很长的内部编号；目录太大时优先发和图鉴名称相关的条目，请求不会超长。
- 逐面抽取：保存的搭配可以删除了（「删除这套搭配」，要再点一次确认）；删除只删搭配本身，已经套用到各面的规则不受影响。
- 逐面抽取去掉「顺序轮播」，只留「随机抽取」，范围仍是你设定的范围。以前设成顺序轮播的，自动按随机抽取处理；本机留着的轮播进度也一并清掉。
- 修复「按 1 亮 2、按 2 亮 3、按 3 亮 1」：模型常把一排按钮写成“提示下一步”——选中第 1 项时去点亮第 2 个按钮，于是按下去的那个不亮、旁边的亮了，看起来像点错或没反应（其实下面的内容已经换了）。现在一组按钮里每一项都恰好去点亮另一项时，高亮改回按下的那个按钮自己；颜色和内容不变。提示里也补了一句：选中高亮落在按下的那个按钮上。
- 带图的兔子镜也能复制、下载本面 HTML：内置生图／插图画进图框后是一整张图片数据，以前一面里有这样一张大图就会被判成“超出安全导出范围”，复制和下载都被拒绝。现在导出时图片先单独拿出来，其余部分照常做安全检查，通过后再把原图放回去，导出的文件里图片完整。
- 自动生成的安全阀不再误判：正文里用 `~~~ 第二天 ~~~`、`~~~~~~` 当分隔线，或者某个标签里少写了一个引号时，以前会被当成“正文没写完、疑似截断”，自动模式下这条回复就不出兔子镜。现在波浪线分隔线按普通文字处理；标签少引号时只要后面还有 `>` 就照常往下看，真的断在半截标签里才算截断。
- 逐面生成多面兔子镜时，某一面在本地预检没通过（比如只有这一面超出请求长度），前面已经有面成功的话只跳过这一面，后面的面照常生成；只有本轮消息或生成归属变了才整轮停下。
- 人设列表翻页、筛选时，不再被当成“换了人设”而中止生图和重试；内置生图被中止时图框里留一个「重新生图」，不会一直停在“绘制中…”。
- 收藏图鉴：编辑格子时改了格子名称，原来手动关联的收藏不再丢失；一边生成草稿一边点别处的保存，编辑区的按钮不会再一直灰着点不了。
- 逐面抽取：把某一类切到「不追加」后，隐藏起来的数量框里的错误不再挡住「保存本面」；同名搭配保存时直接覆盖，连点两下不会多出一份。
- 修复「滑杆是摆设、内容一打开就全部摆出来」的兔子镜：模型有时写一根点不动的滑杆（停在最右边），下面一排章节、条目全部已经显示，说是拖动推进，其实什么也操作不了。现在滑杆格数和条目数正好相等、条目是同一种写法时，会把滑杆放开、从第一格开始：一打开只显示第一条，往右拖（或点 ＋）一条条显示出来，拖回去就收起。不写任何新内容。同时在整体设计说明里补了一句：控件不写成点不动的摆设，要靠操作才出现的内容不要一开始就全部摆出。
- 删楼层、删 swipe 后插图跟着兔子镜一起搬：以前插图按楼层号存在本机，删掉中间的楼层后，后面楼层的插图就对不上、显示不出来（图其实还在）。现在内置生图和手动生图的图、连同手动生图的提示词草稿，都按同一套规则搬到新楼层号；被删掉的那几层的图原样留着，不删；新位置已经有图时不覆盖。只在这台设备上删楼层时生效：在别的设备上删过楼层的，这台设备上的旧插图没法知道该搬到哪一层。
- 关掉「内置生图」以后，之前已经画好的图照样显示在图框里。以前关掉后图框会一直空着；现在关掉只是不再画新图，本机存好的图直接放回去，不会发任何生图请求。
- 柔和浅色不再出米黄：米黄、米白、奶油色、羊皮纸黄这类暖黄纸色不算柔和浅色，不作主背景；信纸、日记、旧书这类纸张也换成其他带灰的颜色来表现纸感。举例色里偏米黄的几种（燕麦、旧纸黄、奶油灰黄、亚麻、象牙灰、浅驼、卡其灰等）也换掉了，同时补上浅粉、蜜桃粉、婴儿蓝、薄荷绿、淡紫这类干净的浅色。
- 新增「色调模式」，设置里原来的「深色模式」勾选框换成三选一的选择框：普通／柔和浅色／深色。选中即保存，从下一次生成起生效，已有作品不变。
  - 普通：和以前完全一样。
  - 柔和浅色：背景和主要承载面用柔和的浅色，不用纯白、米黄和鲜艳的大色块。柔和浅色里有八种风格，每轮随机换一种（最近两轮用过的先不用）：莫兰迪灰调、干净浅色（浅粉、婴儿蓝、薄荷绿……）、浅色传统色（月白、天青、天水碧、藕荷……）、清透空气感、水彩晕染、珍珠贝母、春日花色（樱花粉、丁香紫、嫩芽绿……）、冰雪雾凇（冰蓝、霜白蓝、浅银灰……）。每轮只发这一种风格的一句说明和四个举例色，举例色避开近三轮用过的色族和上次给过的颜色，不会总是那几种；正文用同色相的深灰，能点的地方用一处稍深的同调色，看得清也看得出能点。仍然强避重，只是在浅色范围里换色；连着几面接近纯白时，换一种带色的浅，不会被赶去用深色或鲜艳的底。长文本也走柔和浅色的阅读配色。
  - 深色：就是原来的深色模式，内容不变。以前开着深色模式的，更新后自动是「深色」。
- 滑杆、拖动出现得太多，现在压下去：
  - 以前只有“近期老是翻面、展开”时才换口味，而且换口味的提示把拖动、滑杆排在最前面，等于一直往滑杆上推；现在反过来也管：近三面里有两面用了滑杆或拖动，下一面就不再提供滑杆、拖动类的写法和用法，并提醒主交互换成点按、按住、刮开、累积点亮、重排、描画或整体切换。之后照常可以用。
  - 整体设计候选里“方案 1”原来写着“直接点按或拖动主体”，改成“直接操作主体本身”，不再点名拖动。
  - 每面提供的插件写法里，滑杆、拖动这一族（连续调节、拖动组合、揭开、视野缩放、进度控制）合起来只占一个名额；“连续调节”的别名从四个减到两个。
- 修复「拖滑杆换画面」的另一种写法：模型用 `[value="2"]` 这种按滑杆数值切换的样式，拖动时浏览器不会更新这个数值，画面永远停在第一次的那一档。现在只要本面的样式确实按数值指向这根滑杆，拖动时就把当前数值同步过去，模型写好的切换自己生效；不改任何样式，不猜目标。
- 修复「上面一排按钮、下面一组画面」点了只亮按钮、画面不动：模型先放了一组藏起来的选项去切画面，又在上面另做了一排看得见的按钮，却忘了把两组连起来。现在两组数量一致、名字只差一个后缀、藏起来的那组按 1、2、3… 编号并且确实有切换样式时，点第几个按钮就切到第几页。打开时按钮的高亮跟着当前真正显示的那一页。维修兔也能在隐藏副本里实测这种按钮，不会再报「交互 ID 未隔离」却点了没反应。
- 维修兔不再把「完全没有标签指向、本来也不靠标签点击」的隐藏选项算成「交互 ID 未隔离」。这种情况重新隔离 ID 什么也修不了，以前会亮「可维修」，点了没有任何变化。
- 手机上生成并保存过的兔子镜，滑杆旁边会带着 −／＋ 按钮；以前换到电脑上打开，这排按钮还在但点了没反应。现在电脑上也会接上，不会新增按钮。
- 0～1、步长 0.01 这类很细的滑杆，−／＋ 每点一下大约走 1/20，不再一下只动 1%。
- 横向裁切修复不再去缩放铺在画面上的弹幕层：弹幕本来就是飘出边外再被裁掉的，缩完会错位，还会被当成新的「定宽过宽」反复报。
- 删楼层后兔子镜不再对错号：兔子镜在聊天文件里按楼层号保存，以前删掉中间的楼层后，后面的楼层整体前移，兔子镜却还挂在旧楼层号上，前移的楼层就找不到自己的兔子镜，被删楼层的兔子镜也一直留在聊天文件里占空间。现在删楼层、删 swipe 时，按“是哪一条消息”把每面兔子镜（连同它的版本、存档和历史）跟着搬到新楼层号；被删掉的那几条消息的兔子镜从聊天文件里移除。
  - 不看正文内容，改过正文的楼层、两层正文一模一样的楼层都不会认错。
  - 删楼层时酒馆还没把聊天加载完、或者删掉的楼层不是连续的一段（不像是正常删除）时，这次什么也不改。
  - 删掉过的兔子镜（“已删除”标记）跟着它那层走，不会压到别的楼层上。
  - 在别的设备上删过楼层、或者删完没来得及保存就关掉了页面时，打开聊天会改用聊天文件里的兔子镜版本，不会把别的楼层的旧版本挂到这一层。
  - 收藏夹不受影响，收藏过的兔子镜照常能打开。插图（内置生图和手动生图）也跟着搬到新楼层；被删楼层的插图留在本机，不删。
- 修复「拖动滑杆逐段显示」的兔子镜：模型常写一个 1～4 的滑杆，再写四段默认藏起来的内容，却用只对勾选框生效的写法去切换，拖了什么都不出来。现在能认出这种「滑杆 + 编号段落」结构，滑到几就显示第几段；只在段落编号与滑杆取值一一对应时接上，不写任何新内容。
- 整体设计候选的记录写在 details 里面那层容器上时也能读到，诊断里不再显示「无回报」，近三面用过的交互方式也能照常记录。
- 维修兔不再把知乎、微博这类界面上的赞同、评论、收藏、分享按钮当成「没写结果的按钮」。
- 维修兔整体检修（用 76 面实际生成过的兔子镜把维修兔的每个按钮都点了一遍）：
  - 不再把标题栏自己的两行截断当成「文字被裁切」。以前每一面都会因此亮黄灯，还会去改自己的标题。
  - 「checked 目标位于触发器父层之外」以前只实测第一个开关，其余开关永远算没验证，所以怎么修结尾都写「仍检测到」。现在会在隐藏副本里逐个实测（不动真实控件），测完自动刷新结论；只巡逻时也会补测。
  - 修复几组切换按钮互相干扰：像「意象深层解构 / 前世因果」这种每组各切一块面板的写法，以前维修兔认错目标，会把别组的面板也藏起来，点了不显示。
  - 新增能修的写法：开关包在小容器里、CSS 却按「开关后面的兄弟」去找目标（比如「翻转整叠样卡」）；开关放在 label 外面、样式却写在 label 里面（选中的标签现在会高亮）；画了按钮却没写结果的，点了会提示已记录，不再毫无反应。
  - 「无法命中真实目标的 checked 规则」不再把只对别的开关生效的规则算进来，也认得「开关 + 兄弟里的某个元素」这类浏览器本来就能命中的写法。
  - 「手机端容器挤压」只在看得见的文字或图片真的伸出去时才报；弹幕、轮播、藏起来的浮层、地图钉旁边的名字不再算。
  - 滚动弹幕不再被当成文字被裁切。
  - 提示里的「用挨打猫重说」改成现在的「↻ 重说」。
- 修复刮刮乐、封条、幕布一类「铺满整块的遮盖层本身就是按钮」的兔子镜：揭开上一步后，下一步的遮盖层会跟着塌成一条细线、点不到，交互卡在半路。现在会自动给它补回能点的高度，维修兔「点了没有反应」也会用到这条修复。
- 一层揭开里还套着下一层时，点一下揭开后的正文只退回最里面那一层，不会再一下子整面退回最开始。
- 整体设计候选的记录更稳：模型把记录写坏引号时会自动修好，近三面用过的交互方式也能照常读到；同时说清楚记录里要写实现的方案号。
- 修复「消逝显影」一类用滑杆烧开、晕开、揭开表层的兔子镜：模型写的滑杆脚本会被酒馆删掉，拖了没反应。现在能认出这种「滑杆 + 盖在上面的表层」结构，拖动滑杆就逐步揭开表层；纸上跟着进度走的焦边、水痕也会一起动，方向和表层揭开的方向一致。
- 短锁里的内置生图说明压短了一些，图框的宽度、比例、圆角样式照旧写在模板里；整体设计候选里与其他规则重复的两句删掉了，意思不变。未开启内置生图时没有这一段。
- 新增「亲手做的心意」一组展现形式：亲手写的小程序、亲手搭的纪念网页 / 观测终端、亲手做的贺卡、为你整理的歌单、画给你的地图、准备好的惊喜盒。都是 {{char}} 亲手为 {{user}} 做的东西：署名是角色本人，内容取自两人共同的经历，交互一步步推进，最后落在一句只说给 {{user}} 的话。
- 交互避开翻面／展开模板：插件会从每一面成品的实际结构里认出它用了什么交互机制（翻面、展开、切页、拖动、滑杆、按住、刮开、累积、重排、描画、弹窗等）。近三面里有两面只靠翻面、展开或切页时，下一面会换口味：设计方案改为直接操作主体本身，提供的真实用法里不再出现翻、开、揭一类动作，并提醒主交互换成会直接改变画面的操作，翻面和展开最多作辅助。没触发时不增加任何字数。
- 内置生图在没有设置生图 LLM API 时，提示词按设置里选的提示词格式来写：标签写法写英文短标签，自然语言写法写连贯描述；出场人物的稳定外貌（发色、发型、瞳色等）逐个单独写出、分开发给生图渠道，不再把同一句中文同时当成标签和描述发送。
- 新增小剧场内置生图：感谢@nancyindaeyo做的新功能。设置里「启用小剧场内置生图」，默认关闭。开启后，只有这一面本来会用色块或 SVG 画人物、场景时，才改成一个图框；生成结束后自动调用一次生图渠道把图画进框里。视频的播放画面与封面、照片、插画这些本来就是一幅画的位置，也会换成图框出图。
- 新增智绘姬生图渠道适配：镜面生图里可以选择柏宝绘或智绘姬（二选一）。选智绘姬时，通过酒馆事件把提示词交给智绘姬并按请求编号接回图片，沿用智绘姬里已经配好的模型、接口和出图设置，不修改它的全局设置；图片保存成酒馆本地路径，生成成功但保存失败时会明确提示，不会自动重发。需要先在智绘姬里打开总开关。
- 收藏夹换了新界面：「缩略图」直接显示每一面兔子镜本身的缩小画面，「列表」按标题一行一行排，会记住上次选的排列方式；可以按标题搜索、按角色筛选，删除要再点一次确认。手机上铺满屏幕，电脑上是居中的面板，颜色跟随兔子镜主题。
- 偶尔的续篇：收藏过的兔子镜，有很小的概率迎来续篇——回信、下一页，或之后发生的事，展现形式沿用原来那一面。点菜、按原选题重写时不会出现。
- 里程碑：第 10、50、100 面兔子镜时，会弹出一张小小的纪念卡，可以直接打开收藏夹。纪念卡在本地生成，不请求模型。
- 完成的奖励：小游戏、解谜和养成类展现形式走到最后一步时，会有一个只属于这一面的结尾（一句话、一枚印章或一个小物件）。
- 「原选题重写」按正在看的那一版的选题来写：删掉最新一版、切回旧版后再重写，不会再沿用最新那一版的选题。更新前生成的旧版本没有这份记录，仍按原来的方式处理。
- 多面镜整批重说时，每一面都会各自多出一版，可以翻回旧版，也可以删掉新的那一版。
- 新增两种画面类展现形式：同人图约稿、插画作品投稿页。
- 「虚构影音站」的条目改用界面特征来描述（深色底、站标色、带时长角标的播放器、缩略图网格、点赞比例条、标签云等），不写真实网站名。
- 标题栏的折叠三角箭头全部去掉，点标题照常展开或收起。

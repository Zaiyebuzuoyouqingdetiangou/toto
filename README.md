# 兔子镜小剧场 1.66.8

## 更新日志模块

新增了更新日志板块，感谢 @nancyindaeyo 的更新。

## 本次变动

- 镜面生图新增「生图 LLM API」。设置后，手动生图和内置生图的提示词都由它来写；不设置时，手动生图由副 API 单独请求一次，内置生图的提示词在生成小剧场时由副 API 一并写好，不另外请求。
- 生图 LLM API 和副 API 一样，可以从酒馆所有已配置的连接里选择，也可以一键使用酒馆当前连接（不保存 Key），或手动填写 OpenAI 兼容接口，并能拉取模型、调整温度与最大输出。
- 设置了生图 LLM API 时，生成小剧场的那次请求不再要求写完整的画面描述，图框里只留一两句画面线索；正式提示词由生图 LLM 另写，没写出来时就用这段线索继续出图。
- 新增小剧场内置生图：感谢@nancyindaeyo做的新功能。设置里「启用小剧场内置生图」，默认关闭。开启后，只有这一面本来会用色块或 SVG 画人物、场景时，才改成一个图框；生成结束后自动调用一次柏宝绘把图画进框里。
- 模型正常结束却没有返回任何文字时，提示改为说明这通常是内容安全拦截，并给出处理办法。
- 副 API 的模型直接拒答时，提示里写明是模型拒绝了这一轮、和生图无关，并附上它回复的开头，方便判断是换模型还是在黑名单里排除这类内容。

  - 边缘的暗影按每件东西自己的颜色画，不再每块都是同一圈黑边；画面自己已经画了高光的地方，不再叠第二道。

这一轮接着修「存成长图」和「自动演示」，还有叠着几张纸的那种面。

  - 点开以后，黑幕还盖在字上面。

  - 图上压着对白气泡、拟声字的图，在 iPhone 上存出来图框是黑的、只剩气泡。以前这种认不出「图没画上」；现在认得出，会多等一会儿再画，还画不上就照着页面上那张垫在气泡底下补上，气泡和字不动。这一条只在电脑上模拟过，iPhone 上要是还有黑框，请把那一面发来。
  - 调暗了、糊着、盖着幕布等人点开的图，存出来会变成一张亮的、清楚的图露在外面：修好了，存出来和页面上看到的一样。
  - 半透明的图，补上去的不再是不透明的。
- 🙈 插图打码：有的手机上，翻到后面几页以后，长图和自动演示里会露出没打码的原图。修好了，长图和演示里用的都是打好码的那一张。
- 带图的面存长图更快、更省电：这一刻看不见的图不再放进去，打了码的图只放一份。叠着三张图、又打了码的面，存一次从 3.7 秒降到 2.2 秒（电脑上照手机的速度量的）。
- 没有图的面，「每一页都拼上」比以前慢两三成：每走一步都要照页面上那一套再量一遍。

## 2.60.3 这一轮更新了什么

这一轮做了一次体检：省电、不卡、不闪退。

- 流式输出的时候开着「人名打码」，时间一长酒馆会被手机关掉重开：修好了。以前正文每重画一次，换下来的那一份都被打码记着不放，内存越涨越高；现在换下来的马上放掉。打码本身也轻了一半。
- 标题栏上的小动画：这一面刚滚出屏幕、或者没人碰已经省电停下以后，有的还在看不见的地方一直动。现在跟着停。
- 有很多「按了才出来」内容的面，打开聊天时挂得更快。
- 「存成长图」快了三到四成，面越大越明显；拼的时候画面也不那么卡。拼出来的图和以前一样。
- 自动演示：
  - 演示盖满整屏的时候，后面聊天里的面先停着，不再和演示里的那一份一起动，录屏时没那么烫。
  - 演着的时候不让屏幕自己暗下去、锁上（手机和浏览器支持的话）；暂停、演完、关掉就放开。
  - 演过一遍，过一会儿再点「从头再看一遍」，面里的倒计时、限时反应不走：修好了。
- 生成时的那张进度卡（缝纫兔）：每次更新要重算的东西少了一半；卡上那段小画滚出屏幕也会停。
- 生成报告里多了两句话：等模型回完用了多久、兔子镜自己处理用了多久；等第一个字的时候酒馆开在前台多久。生成慢的时候，一眼能看出慢在哪一边。

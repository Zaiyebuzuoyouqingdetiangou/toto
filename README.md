# 兔子镜小剧场

## 1.63.8 更新日志

- VS 三条候选的结构固定分工：方案 1 只有一个可操作的主体并一步步变化，方案 2 整个媒介一起切换状态，方案 3 结构自由；由程序等概率指定实现哪一条，并列入口最多只会出现在方案 3。
- 近期连续出现“多个入口各显示一段文字”时，程序只在方案 1、2 中指定。
- 连续阶段要在同一个部件上一步步发生，不再做成一排阶段按钮。

## 1.63.7 更新日志

- 修复动态画面里铺满全屏的可点区域盖住标题栏，导致“标题框消失”的问题。
- 近期连续出现“多个入口各显示一段文字”时，换口味的要求同时写进离输出最近的短锁：整面交互作用在同一个主体上，不让每个条目各配一个开关。

## 1.63.6 更新日志

- 交互的深度改为来自同一部件的连续阶段（打开→取出→翻看），不再靠增加并列的同款入口，减少三个按钮并排的情况。
- 本体自己保持完整的外壳：有与媒介相符的底色、边缘和轮廓，与标题栏连成一体；只去掉套在外面的无关框。

## 1.63.5 更新日志

- 交互更深：画面里出现的按钮、开关都要能点并带来变化（新画面、弹窗或状态改变），第一次操作之后还有可以继续的下一步。
- 标题栏改用本体的主色作底，与下方本体连成一体。
- 本体外如果被套了一层只有底色和内边距的装饰框，挂载时会自动去掉这层框，本体直接贴着兔子镜外壳。

## 1.63.4 更新日志

**展现形式落地**
- 生成前先想清楚媒介在现实中的样子、部件和用法，DOM 结构从这些部件反推；短锁新增“去掉标题后仍能认出是什么媒介”的核对。
- VS 整体设计候选从媒介本身的结构和使用方式出发，并写明结果出现在哪里；取证新增 VS 承诺与实际骨架的对照记录（只记录，不重试）。

**交互**
- 切页、折叠、并列开关不再长期禁止：近三轮出现两次才换一次口味，之后照常可用。
- 多个节点的结果就近出现，同时打开时不互相遮挡；镜面里最新打开的说明会自动显示在最上层。
- 动态视觉模式补上交互机制要求（checkbox、radio、details）；只写了状态类名、没有开关的翻面等交互，挂载时会自动接上点击。

**画面与配色**
- 近白浅底不论色相都算同一类，近三轮出现两次后换用带色相的浅底或中明度底；深色冷却改为 3 轮。
- 首个主体内部分出远近层次，不在本体外再套装饰框；图形、装置和场景类的面以画面为主，文字控制在三四百字以内。

**题库**
- 新增 28 条成人向展现形式（数字生活、纸本、媒体、表演、游戏、视觉实验）。

**精简**
- 删除重复与互相矛盾的规则（视觉复杂度保持、常驻切页禁令、重复的文档流说明等），单面请求的规则与短锁合计少了约 900 字符。

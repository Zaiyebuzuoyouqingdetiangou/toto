# 兔子镜小剧场

## 1.63.4 更新日志

**展现形式落地**
- 生成前先想清楚媒介在现实中的样子、部件和用法，DOM 结构从这些部件反推；短锁新增“去掉标题后仍能认出是什么媒介”的核对。
- VS 整体设计候选从媒介本身的结构和使用方式出发，并写明结果出现在哪里；取证新增 VS 承诺与实际骨架的对照记录（只记录，不重试）。

**交互**
- 切页、折叠、并列开关不再长期禁止：近三轮出现两次才换一次口味，之后照常可用。
- 多个节点的结果就近出现，同时打开时不互相遮挡；镜面里最新打开的说明会自动显示在最上层。
- 动态视觉模式补上交互机制要求（checkbox、radio、details）；只写了状态类名、没有开关的翻面等交互，挂载时会自动接上点击。

**画面与配色**
- 近白浅底不论色相都算同一类，近三轮出现两次后换用带色相的浅底或中明度底；深色冷却改为 3 轮。
- 首个主体内部分出远近层次，不在本体外再套装饰框；图形、装置和场景类的面以画面为主，文字控制在三四百字以内。

**题库**
- 新增 28 条成人向展现形式（数字生活、纸本、媒体、表演、游戏、视觉实验）。

**精简**
- 删除重复与互相矛盾的规则（视觉复杂度保持、常驻切页禁令、重复的文档流说明等），单面请求的规则与短锁合计少了约 900 字符。

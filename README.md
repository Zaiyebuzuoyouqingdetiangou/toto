## 2.65.4 这一轮更新了什么

- 「下一轮再生成」：给上一条回复生成到一半时页面重开了（比如切到别的 App 再回来），新页面打开这个聊天时会接着给它生成，不会就这么漏掉。
- 页面关掉或重开的那一下，兔子镜以前会把被打断的那次请求再发一遍（页面已经没了，结果没人收，白花一次）；现在不再发。

## 2.65.3 这一轮更新了什么

- 「下一轮再生成」：页面重开以后（比如切到别的 App 再回来），上一条回复下面等着的卡没了，发下一条消息时也照样给它生成。已经有兔子镜的不会重复生成，在快拍里删掉的也不会补回来。

## 2.65.2 这一轮更新了什么

- 「下一轮再生成」聊久了会越来越慢、越耗电：以前每条回复写完，都要把之前生成过的楼层全部重新过一遍；现在只看还没收尾的那一条。手动生成点得多时也一样。
- 有的环境存档或重画以后，会把聊天里的消息换成一模一样的新一份：「下一轮再生成」以前会因此认不出上一条、不生成，现在照样生成。
- 「下一轮再生成」的卡在回复还没写完时点，会按点的那一刻已经写出来的正文生成；卡上现在写明了。
- 优化了 UI。

## 2.65.1 这一轮更新了什么

- 「下一轮再生成」修了几处：在输入框里打斜杠命令不再被当成下一轮；上一条回复中途按了停止的，下一轮也能正常生成；回复刚写完、卡还没挂出来就发了下一条，也照样生成。
- 「下一轮再生成」也和自动生成一样把关：上一条看着像报错、没写完，或者副 API 连着报同一种错时，先不自动发，卡上写着原因，点一下照样生成。

## 2.65.0 这一轮更新了什么

- 副 API 新增一种生成时机「下一轮再生成」：回复写完先挂一张卡，发下一条消息、下一条回复开始写时，自动给上一条回复生成，两边同时写、互不影响。等不及也可以直接点卡。

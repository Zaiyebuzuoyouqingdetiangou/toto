修好了大家上传的报错（北京时间 11 月 13 日 16:42 之前收到的那些），感谢大家的贡献！每一份打码样本都帮兔子镜找到了一种以前修不到的写法。

**修好的问题**
- 一个开关（勾选框、可以点开的小折叠）管着的东西包在旁边另一个框里时，以前拨了、点开了画面不变（拉灯绳灯不亮、换模式屏幕不换）；现在跟着变。
- 整块写成开关、里面又放了一颗真正的开关按钮的：以前点空白处没反应，维修兔还记成坏了；现在交给里面那颗按钮。
- 帖子里左右两个箭头翻图的轮播：以前箭头点了不动；现在能翻，点赞这些照常。
- 一页一页翻的相册、换台：有几种页码写法以前不认，按「下一页」不动；现在翻得动。横着滑的相册、上一张／下一张写在下面一排的，以前按了也不动，现在能翻。
- 整张卡片点了只是选中、没写选中样子的：点上时描一圈，看得出点上了。
- 明信片这类点一下翻面的卡片：以前点了不翻；现在点一下翻过去，再点翻回来。
- 电视换台这类（面板上一排按钮、屏幕上几个台）：以前按哪个台都是同一个画面；现在按哪个台换到哪个台。
- 正文下方的拖放：以前拖到一半会松手弹回原位；现在能一直拖进格子里。拖着走的东西也不再有「按下去缩一下」的手感。
- 按住充能的按钮：以前按满了，该出来的东西（曲目单、转起来的唱片）不出来；现在出来。
- 地图上的小点、萤火虫这类点开的说明：以前挤成一个字一行的细条，还被切掉一截；现在铺在画面底下看得全，收起后退回原样。
- 不支持原生弹窗的旧手机上，小卡片里弹出的说明以前底下被切掉；现在完整显示，关上还原。
- 维修兔少了一种误报：摇铃这类按下只播一下动画的按钮，不再记成「没反应」。

**其他**
- 新增「图鉴」：点聊天里的小兔子，或兔子菜单里的「🐰 图鉴」打开。衣服按节日、节气、天气这些分类一页一页看，用 ‹ › 换分类、翻页；在这台设备上遇到过的上色、写名字，没遇到的是灰色影子，也写着哪天、什么天气会穿。只画眼前这一页，打开快、省内存。
- 新加了 4 套衣服，在图鉴最后的「特别」一页。
- 有的酒馆美化会把标题栏上的切页按钮、星星，和每面底下的「▲ 收起」变成一大块一大块的按钮，现在这几样不受美化影响，照旧是小小的。

**修好的问题**

- 要分两步打开的东西（先拉开抽屉、再拆封）：拆封以后再碰一下抽屉，信纸连同里面的图被压成一条缝。现在不会了。

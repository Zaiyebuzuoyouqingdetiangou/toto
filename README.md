# 兔子镜小剧场 1.67.13

## 更新日志模块

新增了更新日志板块，感谢 @nancyindaeyo 的更新。

## 本次变动

- 偶尔的续篇：收藏过的兔子镜，有很小的概率迎来续篇——回信、下一页，或之后发生的事，展现形式沿用原来那一面。只有收藏里有能续写的作品时才可能出现；点菜、按原选题重写时不会出现。
- 纪念册：收藏夹新增「纪念册」，把收藏按日期从早到晚排成一本可以翻页的册子，第一页是封面。
- 里程碑：第 10、50、100 面兔子镜时，会弹出一张小小的纪念卡，可以直接翻开纪念册。纪念卡在本地生成，不请求模型。
- 完成的奖励：小游戏、解谜和养成类展现形式走到最后一步时，会有一个只属于这一面的结尾（一句话、一枚印章或一个小物件）。
- 「原选题重写」按正在看的那一版的选题来写：每一版都会记下自己当时的主题和展现形式，删掉最新一版、切回旧版后再按原选题重写，不会再沿用最新那一版的选题。更新前生成的旧版本没有这份记录，仍按原来的方式处理。
- 多面镜整批重说时，每一面都会各自多出一版，可以左右翻回旧版，也可以删掉新的那一版；以前只有第一面会留版本，其他面直接被替换、也没法删。
- 标题栏的折叠三角箭头全部去掉，不只外置框；跟随正文和独立 API 的兔子镜都一样，点标题照常展开或收起。
- 生图提示词参考心迹回廊的组织方式：稳定外貌与本幕场景分开，人物、动作和位置对应；标签模式不再要求用不到的自然语言副本，自然语言模式保留完整画面描述。
- 已配置生图 LLM 时，正文继续只留画框和简短线索；内置图片显示构思、绘制及渠道进度。同面多图仍分别启动，不增加请求或自动补发。
- 生图弹窗和工具界面共用兔子镜主题；生图弹窗使用浏览器顶层并保留旧 WebView 降级、视口适配和独立关闭区域。选智绘姬时按智绘姬检查连接，不再要求柏宝绘。
- 外置标题栏隐藏折叠箭头，仍可点击标题展开或收起；全链路诊断改为下载完整 TXT 报告。
- 跟随正文的可见中文要求移至最终输出前，明确仅约束兔子镜，不改变主回复语言和隐藏生图提示词。
- 保留此前维修、小游戏、点菜对应、交互记录、美化与新图铺满；旧作品和已保存图片不重写。
- 更新后整页刷新，确认版本为 1.67.13。源码与离线验证通过；真实 PC／手机 SillyTavern、TT 和联网模型仍需实测。

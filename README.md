# 兔子镜小剧场 1.65.7

## 更新日志模块

新增了更新日志板块，感谢 @nancyindaeyo 的更新。

## 本次变动

- 配色短检只看近三轮的主背景和主承载面，不再把按钮、强调色等点缀算进去；黑白灰不进色族禁令（白纸、黑底等固有材质照常可用，近白浅底另有提醒）。同一色族的深浅仍算同一种。
- 安全阀：提前生成阶段只静默停下，不因正文还没写完被判“过短”，也不在流式输出途中连续弹提示；正文完成后再统一判断，每条消息同一原因只提示一次。
- 镜面工具菜单恢复「检测更新」。只留这一个键：点一次检测；有新版本时，这个键变成「有更新 · 版本号」，再点开更新日志，确认后才更新并刷新。
- 副 API 自动生成时，正文若是 429、524 等接口报错，或 `<content>`、`<details>`、代码块没有写完，这一轮不自动发请求。手动生成不受影响。
- 增加少量nsfw展现形式。

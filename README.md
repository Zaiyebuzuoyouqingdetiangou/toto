## 2.45.1 这一轮更新了什么

- 小兔子图鉴的几处修正：图鉴里的兔子是静止的画，不再在背后一直跑动画，开着图鉴更省电；只有聊天里的小兔子点了才开图鉴，标题条上的、弹出来的道谢和公告里的兔子照旧；设置、快拍、收藏夹开着时打开图鉴也看得见，不会被压在底下。

## 2.45.0 这一轮更新了什么

- 新增小兔子图鉴：点聊天里的小兔子（等待、生成中、手动生成这些卡上的小画），或兔子菜单里的「🐰 小兔子图鉴」打开。57 套衣服都列着，在这台设备上遇到过的上色、写名字，还没遇到的是灰色影子，但也写着哪天、什么天气会穿。小兔子跟着天时换衣服，要开着天时才会换。

## 2.44.2 这一轮更新了什么

- 优化了 UI。

## 2.44.1 这一轮更新了什么

- 打开聊天时更顺：兔子镜从最近的楼层开始一楼一楼挂上，不再一下子全挂，减少打开时的卡顿和发热。

## 2.44.0 这一轮更新了什么

- 跟随当前 API、显示在「正文下方」时，一条回复出了几面现在一次只看一面，用标题条上的 1/2 左右翻，和外置弹窗、副 API 一样；以前是几面上下摆着、各显示 1/1。展开着翻，下一面也是展开的；酒馆重画这条消息后还停在原来那一面。系统很老、浏览器不认新写法的设备照旧上下摆着。

## 2.43.5 这一轮更新了什么

- 修了「正文下方」的面里，图框有时不出画面、只露出一大段英文画面说明的问题：酒馆美化改过正文段落的样式时会这样，出图进度、失败原因和「重新生图」按钮也被挤得看不见。现在这段说明不再显示，图框里照常是进度和按钮。

## 2.43.4 这一轮更新了什么

- README 只留最近 40 个版本的更新公告，更早的在 UPDATES-2.x.md、UPDATES-1.x.md；更新菜单读公告更快、更省流量。

## 2.42.2 这一轮更新了什么（推荐更新）

- 抽签黑名单可以拉黑一整组了：设置 → 黑名单里，每个大组一个按钮，比如不想看悬疑/怪谈，点一下这一组就都不会抽到，以后这一组新加的也一起排除，再点一下解除。
- 也可以只拉黑其中一支：兔子镜的「本轮抽签 → 📚 全池一览」里进到某一项，顶上点「拉黑这一支」，它和它下面的全都不再抽到。拉黑的组和支在黑名单里列着，随时能解除。
- 缝纫兔和别处的小兔子多了十二件跟着天时换的衣服和小物件：花朝、上巳、观莲节、中元、寒衣节、腊八、小年，冬至、立秋、霜降这几个节气，还有刮风天和起雾天；下冰雹也会打伞了。
- 开着「每一面都出图」时，模型漏放、由兔子镜补上的那张图：卡片能跟着内容长高的面，图现在放进卡片里面，不再贴在卡片外头（以前补过的面不变）。

**修好的问题**
- 有些面的消息、选项点了不展开（开关和要展开的内容中间隔着一行标签）：现在点了会展开。
- 按顺序点键解锁的面：按对了以后，解开的内容一直出不来。现在按对就出来。
- 拖放的面：要拖的东西写在拖放区外面、格子的名字又对不上时，拖不进去。现在能拖进去，放对了格子里的字条会出来。
- 要分两步打开的东西（先拉开抽屉、再拆封）：拆封以后再碰一下抽屉，信纸连同里面的图被压成一条缝。现在不会了。
- 有的面里画了播放键却点了没反应：现在能暂停、继续画面里的动画。
- 维修兔实测不再把「拖动进度的滑杆」「点开揭开自己的涂黑字」误报成没反应。
- 拖放的面（把牌、物件放进格子里）：放进去以后要是冒出一块结果，牌会落在结果上，把字和「重来」按钮盖住，格子里反而是空的。现在牌一直跟着格子，结果和按钮都露着。
- 连线的面：线不再从两头的字上划过去，改成从一块的边上连到另一块的边上。
- 有些面（卡袋、抽屉这类东西贴着底摆的）一打开整块往上伸出去，盖住聊天正文、挡住屏幕。现在这种面保持原来的高度，不再伸出去。
- 按正文挑签：第一次请求失败、自动重试出来的那一面，以前会固定用签单上的第一张、不让模型挑，「本轮抽签」里也没有挑签思路。现在重试时重新抽一组签让模型挑。

## 2.40.8 这一轮更新了什么（推荐更新）

- 修了几处卡顿：
  - 聊天里展开着的兔子镜多、页面又大的时候，翻聊天、生成回复时兔子镜每同步一次，都要让浏览器把整页重新排一遍版，手机上一次就是几百毫秒，一卡一卡的。现在已经排好的面不再重新量。
  - 同时装着会隔几秒重画正文里折叠框、状态栏的扩展（美化、状态栏之类）时，兔子镜以前每次都跟着把挂着兔子镜的几楼整条重新挂一遍，手机上隔几秒就卡几秒。现在别的扩展改的是正文里别的东西，兔子镜不再跟着动。
  - 存下来的某一面是空的（只有标题）时，以前会一秒好几次地反复拆掉重挂，一直占着手机。现在挂一次就停。

## 2.40.6 这一轮更新了什么（推荐更新）

- 上一版新加的两处自动修补（时间线、步骤条「第几站」对不上的，翻牌的牌不见了的）收紧了条件：本来就写对的面不会被改动；上一版要是把哪一面的时间线改错了，重新打开会自动改回来。

## 2.31.13 这一轮更新了什么（推荐更新）

**维修兔「修不好也能看」：🔓 强行进入交互后（重做）**

# 兔子镜小剧场

当前版本：**1.5.23**。用于 SillyTavern 的互动小剧场扩展，根据当前对话生成不同主题、视觉形式与互动内容。

## 安装与更新

在酒馆扩展管理中使用正式仓库地址：

```text
https://github.com/Zaiyebuzuoyouqingdetiangou/toto
```

已有正式版请保持原仓库地址和安装目录，在扩展管理中检查更新。更新前备份扩展与聊天；更新后整页刷新，确认版本为 1.5.23。不要清除站点数据、母本、抽签记录或旧设备缓存。

ZIP 安装：解压“兔子镜小剧场.zip”，将 RabbitMirror 内的文件和子文件夹整体覆盖到原扩展目录，不要与另一份兔子镜同时启用。本包不包含开发测试文件。

最低宿主版本标识为 1.13.0；连接配置复用使用的 Connection Manager 接口要求 1.18.0 或以上，旧宿主可使用手动配置的兼容独立接口。不同云酒馆和移动浏览器仍可能存在兼容差异。

## 主要功能

- 普通单面或 2～5 面生成，每面有独立标题、内容、交互和维修入口。
- 跟随正文 API 或独立 API，内嵌和外置显示设置。
- 增强视觉绘制、动态视觉、个性化视觉提示词。
- 本地 JSON／酒馆世界书母本导入、分类管理、按需抽取。
- 🚫 禁词与文字替换：处理兔子镜可见文字，不额外加入模型 Prompt。
- 维修兔、本地交互恢复、挨打猫反馈、收藏和黑名单。

多面共用一次生成请求，但增加面数可能增加输出长度、耗时和费用。失败不自动补请求；合格面保留，失败面可手动重试。维修只处理已有内容，不能补写截断剧情或空响应。

## 1.5.23 更新

- “抽到”只展示短名称，最多五面逐面列出；保留原始 ID 用于准确抽签、维修和归属，不读取整库来显示名称。旧记录缺名称时明确提示。
- 恢复镜面边界，调整手机上内容根容器的宽度约束与换行；不靠裁切正文掩盖溢出，不修改美化提示或生成作品的配色。
- 外部世界书母本和“🚫 禁词与文字替换”移到高级设置最后；母本入口注明“导入小剧场世界书”。
- 未增加网络请求、后台扫描或常驻计时器，未更改模型、输出额度、流式或重试参数。没有用减少内容来换取生成速度。

保留 1.5.22 的外部母本连续多面抽取修复，以及首次交互初始化和本地维修保存。完整历史见 [CHANGELOG](CHANGELOG.md)，本版验证边界见 [验证记录](docs/ui-mobile-verification.md)。

## 已知限制与数据提醒

- **成品及维修结果跨设备同步尚未实现。** 不要假设换手机或电脑后一定能恢复；请保留原设备缓存与备份。
- **手机发热、卡顿、十几秒点击延迟尚未完成实机验收。** 动态内容可能增加耗电；明显发热时可先关闭动态视觉、减少同时展开的面数。
- 模型输出仍可能裁字、结构不完整、审美趋同或交互失败；不保证每轮视觉效果或生成速度。
- API 费用由所用服务商决定，本地 Token 估算不是账单。
- 公开反馈前请移除 API Key、私人聊天和无权分享的母本；完整诊断也应先检查隐私。

公开发布不等于上述问题已经全部解决。版本验证记录及待验收边界见随包 docs。

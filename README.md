# 兔子镜小剧场 1.67.28

## 更新日志模块

新增了更新日志板块，感谢 @nancyindaeyo 的更新。

## 本次变动

- 删楼层后兔子镜不再对错号：兔子镜在聊天文件里按楼层号保存，以前删掉中间的楼层后，后面的楼层整体前移，兔子镜却还挂在旧楼层号上，前移的楼层就找不到自己的兔子镜，被删楼层的兔子镜也一直留在聊天文件里占空间。现在删楼层、删 swipe 后，会按正文把每面兔子镜（连同它的各个版本）搬到对应的新位置；对不上任何楼层的（它那层已经被删了），从聊天文件里移除。
  - 两层正文一模一样、认不清是哪层的，原样不动；改过正文的楼层靠楼层上的归属标记认领，不会被当成已删除。
  - 正在生成时、酒馆还在切换 swipe 时不处理，稍后再试（重新生成最后一条也会触发删除）。
  - 删掉过的兔子镜（“已删除”标记）会跟着它那层正文走，不会压到别的楼层上。
  - 收藏夹、插图、图片文件都不受影响，收藏过的兔子镜照常能打开。
- 修复「拖动滑杆逐段显示」的兔子镜：模型常写一个 1～4 的滑杆，再写四段默认藏起来的内容，却用只对勾选框生效的写法去切换，拖了什么都不出来。现在能认出这种「滑杆 + 编号段落」结构，滑到几就显示第几段；只在段落编号与滑杆取值一一对应时接上，不写任何新内容。
- 整体设计候选的记录写在 details 里面那层容器上时也能读到，诊断里不再显示「无回报」，近三面用过的交互方式也能照常记录。
- 维修兔不再把知乎、微博这类界面上的赞同、评论、收藏、分享按钮当成「没写结果的按钮」。
- 维修兔整体检修（用 76 面实际生成过的兔子镜把维修兔的每个按钮都点了一遍）：
  - 不再把标题栏自己的两行截断当成「文字被裁切」。以前每一面都会因此亮黄灯，还会去改自己的标题。
  - 「checked 目标位于触发器父层之外」以前只实测第一个开关，其余开关永远算没验证，所以怎么修结尾都写「仍检测到」。现在会在隐藏副本里逐个实测（不动真实控件），测完自动刷新结论；只巡逻时也会补测。
  - 修复几组切换按钮互相干扰：像「意象深层解构 / 前世因果」这种每组各切一块面板的写法，以前维修兔认错目标，会把别组的面板也藏起来，点了不显示。
  - 新增能修的写法：开关包在小容器里、CSS 却按「开关后面的兄弟」去找目标（比如「翻转整叠样卡」）；开关放在 label 外面、样式却写在 label 里面（选中的标签现在会高亮）；画了按钮却没写结果的，点了会提示已记录，不再毫无反应。
  - 「无法命中真实目标的 checked 规则」不再把只对别的开关生效的规则算进来，也认得「开关 + 兄弟里的某个元素」这类浏览器本来就能命中的写法。
  - 「手机端容器挤压」只在看得见的文字或图片真的伸出去时才报；弹幕、轮播、藏起来的浮层、地图钉旁边的名字不再算。
  - 滚动弹幕不再被当成文字被裁切。
  - 提示里的「用挨打猫重说」改成现在的「↻ 重说」。
- 修复刮刮乐、封条、幕布一类「铺满整块的遮盖层本身就是按钮」的兔子镜：揭开上一步后，下一步的遮盖层会跟着塌成一条细线、点不到，交互卡在半路。现在会自动给它补回能点的高度，维修兔「点了没有反应」也会用到这条修复。
- 一层揭开里还套着下一层时，点一下揭开后的正文只退回最里面那一层，不会再一下子整面退回最开始。
- 整体设计候选的记录更稳：模型把记录写坏引号时会自动修好，近三面用过的交互方式也能照常读到；同时说清楚记录里要写实现的方案号。
- 修复「消逝显影」一类用滑杆烧开、晕开、揭开表层的兔子镜：模型写的滑杆脚本会被酒馆删掉，拖了没反应。现在能认出这种「滑杆 + 盖在上面的表层」结构，拖动滑杆就逐步揭开表层；纸上跟着进度走的焦边、水痕也会一起动，方向和表层揭开的方向一致。
- 短锁里的内置生图说明压短了一些，图框的宽度、比例、圆角样式照旧写在模板里；整体设计候选里与其他规则重复的两句删掉了，意思不变。未开启内置生图时没有这一段。
- 新增「亲手做的心意」一组展现形式：亲手写的小程序、亲手搭的纪念网页 / 观测终端、亲手做的贺卡、为你整理的歌单、画给你的地图、准备好的惊喜盒。都是 {{char}} 亲手为 {{user}} 做的东西：署名是角色本人，内容取自两人共同的经历，交互一步步推进，最后落在一句只说给 {{user}} 的话。
- 交互避开翻面／展开模板：插件会从每一面成品的实际结构里认出它用了什么交互机制（翻面、展开、切页、拖动、滑杆、按住、刮开、累积、重排、描画、弹窗等）。近三面里有两面只靠翻面、展开或切页时，下一面会换口味：设计方案改为直接操作主体本身，提供的真实用法里不再出现翻、开、揭一类动作，并提醒主交互换成会直接改变画面的操作，翻面和展开最多作辅助。没触发时不增加任何字数。
- 内置生图在没有设置生图 LLM API 时，提示词按设置里选的提示词格式来写：标签写法写英文短标签，自然语言写法写连贯描述；出场人物的稳定外貌（发色、发型、瞳色等）逐个单独写出、分开发给生图渠道，不再把同一句中文同时当成标签和描述发送。
- 新增小剧场内置生图：感谢@nancyindaeyo做的新功能。设置里「启用小剧场内置生图」，默认关闭。开启后，只有这一面本来会用色块或 SVG 画人物、场景时，才改成一个图框；生成结束后自动调用一次生图渠道把图画进框里。视频的播放画面与封面、照片、插画这些本来就是一幅画的位置，也会换成图框出图。
- 新增智绘姬生图渠道适配：镜面生图里可以选择柏宝绘或智绘姬（二选一）。选智绘姬时，通过酒馆事件把提示词交给智绘姬并按请求编号接回图片，沿用智绘姬里已经配好的模型、接口和出图设置，不修改它的全局设置；图片保存成酒馆本地路径，生成成功但保存失败时会明确提示，不会自动重发。需要先在智绘姬里打开总开关。
- 收藏夹换了新界面：「缩略图」直接显示每一面兔子镜本身的缩小画面，「列表」按标题一行一行排，会记住上次选的排列方式；可以按标题搜索、按角色筛选，删除要再点一次确认。手机上铺满屏幕，电脑上是居中的面板，颜色跟随兔子镜主题。
- 偶尔的续篇：收藏过的兔子镜，有很小的概率迎来续篇——回信、下一页，或之后发生的事，展现形式沿用原来那一面。点菜、按原选题重写时不会出现。
- 里程碑：第 10、50、100 面兔子镜时，会弹出一张小小的纪念卡，可以直接打开收藏夹。纪念卡在本地生成，不请求模型。
- 完成的奖励：小游戏、解谜和养成类展现形式走到最后一步时，会有一个只属于这一面的结尾（一句话、一枚印章或一个小物件）。
- 「原选题重写」按正在看的那一版的选题来写：删掉最新一版、切回旧版后再重写，不会再沿用最新那一版的选题。更新前生成的旧版本没有这份记录，仍按原来的方式处理。
- 多面镜整批重说时，每一面都会各自多出一版，可以翻回旧版，也可以删掉新的那一版。
- 新增两种画面类展现形式：同人图约稿、插画作品投稿页。
- 「虚构影音站」的条目改用界面特征来描述（深色底、站标色、带时长角标的播放器、缩略图网格、点赞比例条、标签云等），不写真实网站名。
- 标题栏的折叠三角箭头全部去掉，点标题照常展开或收起。
- 修复核心初始化中途异常后仍被当成已就绪的问题；等待异步初始化完成后再标记就绪，禁用或运行实例被替换后，不再补挂旧实例等待中的宿主事件。
- 正常正文不再仅因使用 HTML／DOCTYPE 外层而被判定为接口报错；真实接口错误、限流和网关超时仍按明确错误信息识别。
- 更新后整页刷新，确认版本为 1.67.28。

# RabbitMirror 0.33.81 TEST — 点菜 QR 完整分类同步修复

本版以 RabbitMirror 0.33.80 TEST 实际源码为唯一基线，仅修复点菜 QR 同步与下载缓存问题。

## 修复内容

- Menu QR 升级为 v2.2。
- 0.33.80 新增的 17 个主题元素与 14 个展现形式，已真正并入各自原有分类层级。
- 删除仅用于临时汇总的“0.33.80 新增”入口，避免看似同步、实际原分类仍缺项。
- 主题点菜菜单完整覆盖 118 个主题元素。
- 展现形式点菜菜单完整覆盖 191 个展现形式。
- QR 下载资源改为 `RabbitMirror-MenuQR-v2.2.json`。
- 下载 URL 增加 `rmv=0.33.81` 缓存破除参数，避免扩展升级后仍下载旧 v2.1 文件。

## 2.75.0

**新功能**

- 问卷兔：「工具 › 第一次使用兔子镜」最上面多了一行「跟随你的喜好一键配置」。问卷兔一题一题问你想怎么玩，每题都有大白话说明，不懂的选「推荐」就行；跟你的选择无关的题会自动跳过。
- 开头先说清楚哪些东西要你自己准备（副 API、生图插件、母本库、世界书……），配好的打勾。做到某一题发现没配好，可以直接点「去配置」，配完点底下的「回到向导」接着做，答案都还在。
- 最后看一眼小结，想改哪条点哪条；点「就这样！」一次配好。原来的设置会先存一份，反悔了在小结页点「恢复到上次配置之前」。
- 新装兔子镜的人，第一次打开设置时会问一句要不要问卷兔帮忙。

**更好用**

- 设置里跟你现在的生成方式无关的选项不再显示（比如跟着正文写时，不再列出副 API 才用得上的那几项），设置本身原样留着。
- 标签过滤里会标出正文所在的那个标签（通常是 content），勾上时提醒一句，免得把正文过滤掉。
- 设置开着时，兔子小窗的提示以前会被设置盖住看不见，现在显示在设置上面。

**新功能**

- 插图打码的黑条、黑胶带叉、警戒胶带能转方向了：点一下图上的遮挡，下面「方向」那一排 ↺ ↻ 每次转 15 度，中间的滑杆细调，「摆正」回到横着。
- 兔子镜自己的提示换成从底下冒出来的兔子小窗：出了问题它挠头，做好了它叼走一张小纸条，删掉了它拿扫帚扫走；几句话接连出来叠在同一张里，点一下就关。
- 设置首页版本号旁边多了「新功能 ›」：有没看过的新功能会亮个小红点，点开列出新加了什么，每样都能直接跳过去。
- 「副 API 什么时候生成」换成四张卡片，一句话写清楚；iPhone、iPad 上页面闪退后再进来，用「自动生成」的会问一句要不要换成「下一轮再生成」（可以点「别再提醒」）。
- 收藏夹、快拍页数不多时，翻页变成一排小脚印，点哪只就到哪页。

**更省电、更顺**

- 长倒计时的面挂在屏幕上时，放着不动也一直在忙的那部分活少了八成；还去掉了一处聊天里每出一个字都要跑一次的检查，长聊天更省电。
- 手机上开着键盘打字（比如打拼音，候选栏一会儿多一行、一会儿少一行），兔子镜不再跟着把整个聊天重新排一遍。
- 重说时状态条下面的进度不再一闪一闪，重说进行中打字也更顺；把那一楼滑走再滑回来，「正在重新生成」的提示和进度还在。第一次生成时，进度卡也不会被重画一遍。

**本机存储**

- 在酒馆里删掉聊天时，这台设备上这个聊天的兔子镜备份一起删掉；「清理兔子镜的本机存储」里点「统计所有聊天」，也能找出以前删掉的聊天留下的备份，确认后清掉。
- 以前怎么都清不掉的旧副本，会自动搬进浏览器的版本存档（不占那 5MB，在「兔子镜历史」里还能翻到）；搬不了的单独列出来，自己勾了才清。
- 待修样本箱最多占 0.5MB（以前 2MB），攒满了会问你要不要发给作者、发完删掉。
- 「清理兔子镜的本机存储」那一页的说明改得更短、更好懂。

**修好的毛病**

- 插图被挤得看不见（比如放在翻过来看的卡片正面、写死了高度的屏幕里）：图框不再被挤扁。
- 翻过来看的卡片，翻着的时候存下来，下次打开那一面不再一直藏着。
- 多人卡抽到性转时，问「转谁」的窗口里列的是正文里的人，不会再把卡名当成一个人。
- 按钮在一处、内容在另一处的「点一下看看」（比如点星图上的星星，下面换一张记录卡），点了会跟着换，一次只看一张。
- 维修兔：补不出来时说清楚缺的是按钮、还是按了要变的那一块、还是它不认识的写法；铺在图上的「抹一下」也会去试；报告里不再出现「button」「div」这种词；补测完开关以后，别的结果不会被盖掉。
- 优化了 UI。

## 2.69.0 这一轮更新了什么

- 抽到性转时的小窗只问「转谁」，点一下就开始写；也能换一个主题，或者这个聊天以后不抽性转。其他几类主题不再每次问。

## 2.68.0 这一轮更新了什么

- 新功能：抽到性转、身体互换、权力倒错这类会把人物换个样子的主题时，开始写之前先弹一个小窗问你：性转转谁、两人原来的关系要不要保持不变；也可以直接换一个主题，或者以后不抽这一类。你自己点的题材不会问。
- 修了兔子镜有时把正文里两人的关系、谁是哪种角色写反的问题。
- 直播间那种画面（弹幕、主播信息本来就压在画面上）不再被重新排开。
- 新功能指引里「跟随酒馆主题」那一条点「去看看」能跳过去了。
- 优化了 UI。

## 2.67.1 这一轮更新了什么

- 生成的图上的字重新排开时，修了几处：对话框角上带一闪一闪小箭头的，照样会挪开；一叠卡片（拍立得、可以滑走的卡）、盖在图上的盖子，不再被拆开；用旧版本存下的面重新打开时，位置不再跑偏。
- 钉在角上的按钮给正文留空白时，同一块里有按位置摆好的热点（找不同那种）就不动，免得热点和图对不上。
- 「摊开读」「看看会发什么」两个窗口不再被主题给弹窗写的样式带偏。
- 色调「跟随酒馆主题」：聊天背景是视频时不再误判成浅色；两套设置来回切换时，各自记下的那种不会被另一套盖掉。
- 优化了 UI。

## 2.67.0 这一轮更新了什么

- 新功能：「色调模式」多了一项「跟随酒馆主题」。酒馆主题是深色，新生成的兔子镜就按深色配色；是浅色，就按柔和浅色配色。判断不出来时按你切过来之前选的那种，设置里会写明现在跟成了什么。已经生成的不会跟着变。
- 优化了 UI。

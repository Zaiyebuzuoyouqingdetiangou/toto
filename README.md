# 1.66.0 · 小剧场内置生图

- 设置里新增「启用小剧场内置生图」，默认关闭。开启后，小剧场仍按原来的方式做界面。
- 只有这一面本来会用色块或 SVG 画人物、场景时，才改成一个图框，并写一段画面提示词。不需要画面的面不写图框，也不生图。
- 生成结束后，有图框的面自动调用一次柏宝绘，把图画进框里。不再另请副 API 构思提示词。柏宝绘没连好时，小剧场照常留下，提示词还在框里。

# 兔子镜小剧场 1.65.9

## 更新日志模块

新增了更新日志板块，感谢 @nancyindaeyo 的更新。

## 本次变动

- 画出来的控件必须有结果：VS 每条方案要写出画面上每个控件（播放键、按键、开关、旋钮等）按下后的结果，没有结果的控件不画；短锁同步提醒，并举例“播放键让唱片转、进度走、歌词滚动”。
- 播放器的播放／暂停键画出来却没接上时，挂载时自动接成“暂停／继续画面里已有的动画”，按键图标随状态切换；画面里没有动画、或已用插件驱动的进程控制时不处理。短锁提醒画面里的播放键、按键都要真的能用。
- 配色短检只看近三轮的主背景和主承载面，不再把按钮、强调色等点缀算进去；黑白灰不进色族禁令（白纸、黑底等固有材质照常可用，近白浅底另有提醒）。同一色族的深浅仍算同一种。
- 安全阀：提前生成阶段只静默停下，不因正文还没写完被判“过短”，也不在流式输出途中连续弹提示；正文完成后再统一判断，每条消息同一原因只提示一次。
- 镜面工具菜单恢复「检测更新」。只留这一个键：点一次检测；有新版本时，这个键变成「有更新 · 版本号」，再点开更新日志，确认后才更新并刷新。
- 副 API 自动生成时，正文若是 429、524 等接口报错，或 `<content>`、`<details>`、代码块没有写完，这一轮不自动发请求。手动生成不受影响。
- 增加少量nsfw展现形式。

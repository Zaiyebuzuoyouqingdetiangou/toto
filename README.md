- 有好几个按钮的面（比如先开机、再调台）：后一个按钮该播的动画（封面翻走、内页翻进来）一显示出来就自己播完了，等按到它画面不变。现在按到它才播。
- 一排「听一听」「敲一敲」这类按钮，底下一列结果一开始全摆着、按哪个都不变：现在按哪个出哪段。
- 按钮写在画面外面的翻牌、翻面，按了不翻：现在会翻。
- 按完几下才解开的锁（密码锁、拨号），按完了锁不走、后面的相册不出来：现在会出来。
- 一排小标签（每个标签对应下面一段内容）点了不出对应那段：现在点哪个出哪段。

## 2.48.2 这一轮更新了什么

## 2.48.1 这一轮更新了什么

- 「发送前转换」复查后修了几处：
  - 开着「发送前替换词语」时，这一面的生成记录不完整（导出的生成报告里缺这一面的成品和结论）；现在正常。
  - 开着「输入转成 Unicode 编码」时，这个聊天里 user、char 的名字有几处还是原样发出去的；现在一起转。多面逐面生成时，转的范围也和一次生成时一样了。
  - 模型照着把回复也写成 \uXXXX 时，会自动换回正常的字。
  - 替换词：英文名不会再换掉别的单词里同样的字母（填 Ann 不会动 Anna）；原词带空格或英文标点时，换回原词不会弄坏面里的脚本；填的词不会再碰到请求里兔子镜自己的标记（以前个别词可能让请求发不出去）。
  - 开着替换词语时，等待卡以前每来一点字就把全文换一遍，现在隔一小会儿换一次，手机上省内存。

## 2.48.0 这一轮更新了什么

- 新增「发送前转换」：设置 → 它可以参考什么 → 发送前转换。只用在副 API 的请求上，两项默认都关着。
  - 发送前替换词语：自己填「原词 => 代号」（几个叫法共用一个代号时用顿号隔开），发给模型前把聊天资料（正文、角色卡、Persona、世界书）里的词换成代号，兔子镜回来以后再换回原来的词。
  - 输入转成 Unicode 编码：发给模型前把聊天资料里的字转成 \uXXXX 形式的编码，兔子镜回复照常是中文。会多用一些 token，生成也会慢一些。

## 2.47.16 这一轮更新了什么

- 「点一下弹出来的东西，它就收回去」「点面里的空白处，整面回到开头」这两条，现在所有的面、所有的互动都算数（上一版只管了其中几类）：
  - 点开以后才出来的卡片、下一层、展开的内容，点它一下就收回去，别的入口又能点。能只收这一样的只收这一样，别处开着的不动。整格都能点的那种（比如拉开的抽屉），点里面拉开以后才出来的东西也一样。
  - 点面里的空白处，整面回到开头。整块是互动区域的面、要拖要刮的面、摆着内容的那块的留白——以前点了没反应的，现在都可以。
  - 不算的：卡片里的按钮、链接、图框照常各管各的；翻页翻到的那一页（它有自己的上一页／下一页，点上面的字不会翻回去）；拖完、划完松手的那一下；刚点开紧跟着的那一下；用鼠标双击、连点选字的那几下。
- 整面回到开头的时候：面里自己能滚的那一块不再跳回最顶上，底下的「收起」不会多出一个。

## 2.47.15 这一轮更新了什么

- 点开一个东西以后回不去、别的也点不到了：出来的卡片把别的入口盖住，或者入口整个收起来只剩结果。现在点一下那张卡片就收回去；整面是一整块互动区域的面，点面里的空白处也能回到开头了（以前这种面点空白没反应），可以接着看别的。

## 2.47.14 这一轮更新了什么

## 2.47.13 这一轮更新了什么

- 一层层揭开的面（箱子、信封、匣子这类：先掀盖、再拿开上面一层，最后才看到内容）：以前没点之前整面就已经是点完以后那么长，好几屏高的一块板上只有一个按钮。现在没点完之前只留到那块板该有的高度，点完了内容再照自己的长度显示，收回去又回到原来的高度。
- 同一类里，内容没有藏起来、只是被一块实心的板盖着的，也一样处理。
- TT 手机上点一下被算成两下：叠着几层的东西（一层盖一层）点一下会连着点掉两层，中间那层一闪就过去了；盖子点开后手指底下正好是空白处的，会马上弹回开头。现在点一下只算一下。

## 2.47.12 这一轮更新了什么

- 内置生图：图还在画的时候，同一个图框以前会被重复登记好几次，图一回来同一张图被连着放进去四五遍（手机上白白多解码几遍）；现在只放一次。
- 「做到哪一步」里多记了网页字体的加载（开始取、接上、字到了），再遇到页面突然没了，看得出是不是正赶上加载字体。

## 2.47.11 这一轮更新了什么

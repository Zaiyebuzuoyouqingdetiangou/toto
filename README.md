## 2.78.11 这一轮更新了什么（2.78.4 以来）

```rabbit-bow
      (\(\
      ( -.-)    ……鞠躬
    o_(")(")       谢谢大家！
```

**点了没反应**

- 跟随正文的面，有的按钮点了像没反应（勾上又被取消、打开又被关上），在快拍里却是好的：找到原因了，同一面被接了两次线。现在一面只接一次。感谢发来样本还写了备注的朋友，这条就是照着那句「外面点了没反应，快拍里是正常的」找到的。
- 几种互动修好了：当成一张牌写的图框缩成看不见（看不到图）；掌机上的抽签键写在屏幕外面，按了不抽；街机一类「按住结算、连点返回」的面一打开屏幕是空的；待办清单里每一项的「上移／下移」按了不动。
- 维修兔少报一种：拨盘上的数字是靠样式换的（密码锁那种），以前被记成「按了没反应」。

**看得清、排得满**

- 深色面上的暗色字（深红字压在深色纸上）、浅色面上的浅灰字：太难认的会自动挪到看得清，颜色还是原来那个色调。隐形墨水、遮蔽字、要刮开的字不动。
- 写死宽度的面（手机壳、小卡片）在大屏手机上比标题窄一圈：现在铺满。
- 一面里好几列字都要左右滑时，不再每列后面各跟一排「← →」；还有字的那一边会淡出一点，手指直接拖就行。
- 面里另写了深色模式配色时，浅色模式的设备上标题栏和面一深一浅：修好了。

**美化、TauriTavern**

- 把消息排成格子的美化（头像、名字、时间各占一格）下，兔子镜被挤到右边、整条消息被撑出屏幕：修好了。
- 连不上 GitHub 时反复弹「后端错误 … Git handshake failed」：兔子镜自动检测更新以前每次都要问一遍酒馆，现在问过就记着，不再一直弹。自己点「检测更新」照旧。

**其他**

- 看大图、存成长图、打码图的「分享」「下载」前面画上了小兔头。
- 生图面板里「记住」那个勾选框勾上了看不出来：修好了。
- 开了外部母本库时的几处同类毛病一起修了：续写会接在「本轮抽取来源」那行后面、收藏认不出已经收过、维修兔和挨打猫都关掉时标题栏上的工具整条不见。

## 2.78.3 这一轮更新了什么（2.76.23 以来的汇总）

```rabbit-bow
      (\(\
      ( -.-)    ……鞠躬
    o_(")(")       谢谢大家！
```

**新玩法**

- 擦一擦：盖着雾气、灰尘、刮刮乐涂层的面，手指抹到哪儿就露出哪儿，擦开一大半剩下的自己淡掉。擦完以后那一块照常能划动页面，按「复原」可以再擦一遍。
- 摇一摇：摇签筒、骰盅这类抽签，手机摇一摇也能抽。苹果手机要先允许读晃动：面上写着让人摇的，第一次点抽签钮时会问一次；不给就照旧用点的。电脑上、读不到晃动的地方也照旧用点的。
- 互动没写完整的面也有反应了（感谢发来的样本）：滑杆拖了画面一点不变的，旁边的画或文字会跟着变亮变暗；按钮按了东西不动的，那个东西会弹一下。

**iPhone、iPad**

- 长按兔子镜画的图，有人一按整页就被系统收走、酒馆重开。现在这几张图的长按由兔子镜自己接：按住不到半秒，在页面里打开大图，用下面的「分享」「下载」保存。存成长图、打码图做好的那一张也一样，用「分享」存进相册。
- 把酒馆加到主屏幕打开时，导出文件（存档清单、体检报告、美化、备份这些）以前点下载会把整页换成那份文件、回不来；现在交给系统的「分享」，可以存进「文件」。
- 手指正在划、正在点的时候，后台的检查（维修兔巡逻、美化体检）先等着，手停下来再做，划屏更顺。

**副 API**

- 选了「手动生成」或「下一轮再生成」：那张等你点的卡，重开页面、切到别的聊天再回来，或者在 TauriTavern 里放几分钟就不见了，那条回复再也没地方点。现在最新那条回复确实还没有兔子镜时，会把卡补回来（只挂卡，不会自己去生成）；卡还在的时候点它也不会没反应了。

**插图**

- 图框放在圆的、椭圆的、拱形的东西里（圆镜、椭圆相框、舷窗）：以前圆镜会被压成椭圆，或者一张方图盖在圆镜上。现在照那个东西的形状裁，它自己不变形；要横图还是竖图也按它的形状定。

**其他**

- 新增「🩺 最近几面体检」（设置里，也可以放进兔子菜单）：新生成的面点开以后，闲下来时量一次字看不看得清（颜色对比够不够、字是不是太小），只量不改。结果记在这台设备上，重开页面还在；正在出图、手指正在划的时候不量。
- 远处的面划走再回来，擦过、调过的样子不会坏：擦完了的照旧算擦完，按「复原」能盖回去。
- 手机上「页面突然没了」的记录更准：正常关页面、刷新（包括更新后自己刷新）以前也被算成「没了」，现在不算。还是只有数字，没有任何内容。

**修了发来的待修样本**

- 字叠在一起：手机上两页叠成上下两页、上面那页能滑着看的面（翻开的日记本这类），点开批注以后字多了，有时第一段和第二段会叠在同一处。现在不会了；已经叠着的，重新打开这条消息就好。
- 字叠在一起：滑开、刮开式的盖子（盖着底下一页秘密的那种），盖子有时是透明的，盖子上的字和底下的字叠在一起。现在盖子会照原来写的颜色盖住底下，滑开才露出来。
- 一排选项写成单选框、点了内容不换的那种面（几个按钮切换几段字）：现在点哪个出哪段。
- 一颗旋钮、拨杆里藏着两三个选项的：以前点了不动，现在点一下换到下一项，到最后一项再回第一项。
- 一列能上移下移的评论里，有一条自己还能连着点赞的：以前这一条的上移下移按了不动，别的条挪的时候也会跳过它；现在都能挪。
- 一层套一层的步骤折叠（第一步里套着第二步……）：打开第二步时标题不见了、点说明就收起来，现在照普通折叠用。已经这样的，打开外面那一步就好。

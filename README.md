# RabbitMirror 兔子镜 — 0.34.0 Public Beta 2

RabbitMirror 是一个用于 SillyTavern 的互动小剧场扩展。它会根据当前对话抽取主题与展现形式，在回复末尾生成一面可交互的“兔子镜”，并提供挨打猫审美反馈、小小维修兔、母本限量检索及每轮注入统计。

## 安装

1. 在 SillyTavern 的扩展管理中使用本仓库地址安装，或下载本版本 ZIP 后按第三方扩展方式安装。
2. 安装完成后刷新 SillyTavern。
3. 打开扩展设置，确认“兔子镜自动注入”已启用。

更新前建议备份当前插件目录。卸载时删除 RabbitMirror 扩展目录；浏览器本地保存的设置可在插件设置中重置。

## 主要功能

- 随机抽取主题与展现形式；
- 用户可在最后一条消息中直接写明本轮兔子镜主题或展现形式；
- `compact / balanced / full` 三档母本检索；
- 挨打猫 v1.4 多项审美反馈；
- 小小维修兔 v1.59：仅在用户点击后检查或维修当前兔子镜；
- 每轮 RabbitMirror 注入字符数与 Token 估算；
- 手机 Safari / WebView 的交互、裁切与 3D 翻面兼容补救。

## 本 Public Beta 2 的变化

- 公开安装包不再附带、提供下载或依赖任何 Quick Reply／点菜 QR；插件设置中的“用户指令优先”只处理用户在最后一条消息里手动写出的兔子镜要求。
- 例如可直接输入“这次兔子镜用短信体”或“兔子镜主题：共同回忆”；未明确指定时仍按插件随机抽取。
- 全链路诊断不再临时点击当前页面的真实 checkbox。
- 诊断会复制当前兔子镜到隐藏隔离副本，只在副本中直接改变 `checked`，不调用 `.click()`，也不派发 `click / input / change` 事件；验证结束后立即删除副本。
- 无法在副本中安全确认的结构只会报告“未完成安全动态验证”，不会退回操作真实控件。
- “本轮 RabbitMirror 注入”面板改为固定暖色浅底和深色文字，不再受主题变量影响变成黑底黑字。
- Prompt 正文、输出锁顺序、母本预算与每轮注入量均未增加。

## Token 说明

RabbitMirror 会在正式生成时追加自身 Prompt。实际长度随抽取组合与设置变化，请以设置顶部“本轮 RabbitMirror 注入”的精确字符数和估算范围为准。统计面板本身、维修兔诊断和隐藏副本验证都只在浏览器本地运行，不会额外注入模型。

SillyTavern 的提示词拆分界面可能把同一份内容同时归类在“扩展程序”和“聊天记录”中，这不表示模型接收了两份。

## 小小维修兔边界

- 只修模型已经输出的 HTML、CSS 与现有交互结构；
- 不凭空补写不存在的剧情、答案或结果；
- 原始输出已中途截断且没有完整来源时，只能提示重新生成；
- 完整诊断可能包含当前兔子镜正文，公开反馈前请自行检查隐私；
- 全链路控件验证使用隐藏隔离副本，不操作当前页面真实控件。

## 隐私与数据

- RabbitMirror 不包含遥测，不主动向开发者上传聊天内容或使用数据；
- 设置、抽取冷却、挨打猫状态和 Token 数字记录保存在浏览器本地；
- Token 测算不保存完整 Prompt；
- 完整诊断可能包含当前角色扮演正文；
- 某些塔罗展现形式可能加载第三方牌面图片。

## 内容提醒

本扩展面向成年角色扮演用户。随机主题可能涉及成人、恐怖、支配关系、催眠、羞辱或强烈情绪内容，请根据自身接受范围使用随机功能或手动指定。

## 已知限制

- 不同模型、SillyTavern 版本、浏览器和其他扩展组合可能产生差异；
- Token 数量是跨模型估算，字符数才是精确值；
- 浏览器自动检查不能完全代替真实 iPhone / WebView 真机验证。

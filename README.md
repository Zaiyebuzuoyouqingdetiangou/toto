## 2.65.0 这一轮更新了什么

- 副 API 新增一种生成时机「下一轮再生成」：回复写完先挂一张卡，发下一条消息、下一条回复开始写时，自动给上一条回复生成，两边同时写、互不影响。等不及也可以直接点卡。

## 2.63.15 这一轮更新了什么

## 2.62.4 这一轮更新了什么

这是上一个正式版（2.61.15）以来的汇总。

**新功能**
- 母本库可以自己写条目了：点「写一条」，选好是主题、展现形式还是纯文本，写上内容就能存，不用先存成文件再导入。

- 快拍里看不到跟随正文模式画的插图：修好了，整页和镜片两种看法里都有图。
- 回复开头是别的折叠（比如状态栏）时，快拍里挂出来的不是兔子镜：修好了。

- 换设备导入整库、从酒馆备份恢复时，两边都有「我写的小剧场」会把本机没有的条目补进来，不再整本跳过。

**其他**
- 「回退版本」只保留 2.61.18 及以后的正式版。
- 「我写的小剧场」里在「本轮抽签」点过「不再抽这条」的条目会标出来，可以放回抽签。

# 兔子镜小剧场 1.67.18

## 更新日志模块

新增了更新日志板块，感谢 @nancyindaeyo 的更新。

## 本次变动

- 情侣头像可以直接用了：开启内置生图时，「头像 / 情侣头像」只画一张横向双人图，兔子镜里自动切成左右两个方形头像并排显示，画风和配色天然一致。每个头像下面有「保存左边 / 保存右边」，裁成正方形图片：电脑上直接下载，手机和 TT 里可以长按图片保存。
- 收藏夹已经能按缩略图或列表浏览，去掉了功能重复的「纪念册」；里程碑纪念卡上的按钮改为直接打开收藏夹。
- 收藏夹可以切换两种排列：「缩略图」是一块块镜片，「列表」按标题一行一行排，带一小块颜色标记、日期和角色。会记住你上次选的排列方式。
- 收藏夹换了新界面：每一面收藏是一块「镜片」，颜色取自那一面自己的主色，下面写着标题、日期和角色；可以按标题搜索、按角色筛选；删除要再点一次确认。手机上铺满屏幕，电脑上是居中的面板，颜色跟随兔子镜主题，酒馆网页、手机浏览器和 TT 都能打开。
- 新增智绘姬生图渠道适配：镜面生图里可以选择柏宝绘或智绘姬（二选一）。选智绘姬时，通过酒馆事件把提示词交给智绘姬并按请求编号接回图片，沿用智绘姬里已经配好的模型、接口和出图设置，不修改它的全局设置；图片保存成酒馆本地路径，生成成功但保存失败时会明确提示，不会自动重发。需要先在智绘姬里打开总开关。
- 新增三种画面类展现形式：同人图约稿、头像 / 情侣头像、插画作品投稿页。
- 开启内置生图时，视频的播放画面与封面、照片、插画、头像这些本来就是一幅画的位置，也会换成图框出图。
- 「虚构影音站」的条目改用界面特征来描述（深色底、站标色、带时长角标的播放器、缩略图网格、点赞比例条、标签云等），更像真实的视频站，又不写真实网站名。
- 偶尔的续篇：收藏过的兔子镜，有很小的概率迎来续篇——回信、下一页，或之后发生的事，展现形式沿用原来那一面。只有收藏里有能续写的作品时才可能出现；点菜、按原选题重写时不会出现。
- 里程碑：第 10、50、100 面兔子镜时，会弹出一张小小的纪念卡，可以直接打开收藏夹。纪念卡在本地生成，不请求模型。
- 完成的奖励：小游戏、解谜和养成类展现形式走到最后一步时，会有一个只属于这一面的结尾（一句话、一枚印章或一个小物件）。
- 「原选题重写」按正在看的那一版的选题来写：每一版都会记下自己当时的主题和展现形式，删掉最新一版、切回旧版后再按原选题重写，不会再沿用最新那一版的选题。更新前生成的旧版本没有这份记录，仍按原来的方式处理。
- 多面镜整批重说时，每一面都会各自多出一版，可以左右翻回旧版，也可以删掉新的那一版；以前只有第一面会留版本，其他面直接被替换、也没法删。
- 标题栏的折叠三角箭头全部去掉，不只外置框；跟随正文和独立 API 的兔子镜都一样，点标题照常展开或收起。
- 生图提示词参考心迹回廊的组织方式：稳定外貌与本幕场景分开，人物、动作和位置对应；标签模式不再要求用不到的自然语言副本，自然语言模式保留完整画面描述。
- 已配置生图 LLM 时，正文继续只留画框和简短线索；内置图片显示构思、绘制及渠道进度。同面多图仍分别启动，不增加请求或自动补发。
- 生图弹窗和工具界面共用兔子镜主题；生图弹窗使用浏览器顶层并保留旧 WebView 降级、视口适配和独立关闭区域。选智绘姬时按智绘姬检查连接，不再要求柏宝绘。
- 外置标题栏隐藏折叠箭头，仍可点击标题展开或收起；全链路诊断改为下载完整 TXT 报告。
- 跟随正文的可见中文要求移至最终输出前，明确仅约束兔子镜，不改变主回复语言和隐藏生图提示词。
- 保留此前维修、小游戏、点菜对应、交互记录、美化与新图铺满；旧作品和已保存图片不重写。
- 更新后整页刷新，确认版本为 1.67.18。源码与离线验证通过；真实 PC／手机 SillyTavern、TT 和联网模型仍需实测。

# 兔子镜小剧场 1.67.4

## 更新日志模块

新增了更新日志板块，感谢 @nancyindaeyo 的更新。

## 本次变动

- 新增六种适合内置生图的画面类展现形式：电影海报、杂志封面 / 写真内页、游戏 CG 鉴赏、风景明信片集、拍立得墙、绘本跨页。
- 新增九种小游戏展现形式：找不同、翻牌配对、迷宫寻路、寻物房间、钓鱼小游戏、种花小院、料理小游戏、猜拳 / 比大小、密码箱；都配了各自的核心玩法。
- 新增五种换装类展现形式：捏脸 / 角色创建、化妆台试妆、发型屋、装扮小屋、装备栏 / 衣橱；心跳回忆 GS 模式新增「约会换装」。
- 核心玩法从 27 组扩充到 63 组，补上视觉小说、心跳回忆、恋爱综艺、直播、小红书、豆瓣、段评、短剧、跑团、肉鸽、沙盒、解谜、修仙养成、卡牌对战、海龟汤、问卷测验、迎亲游戏、二手交易、输入法联想等形式各自的标志性操作，以及所有换装类形式的换装操作。
- 开启内置生图时，画面要随交互改变的（换装、捏脸、化妆、布置房间等）仍用 SVG/CSS 画，不换成图框，保证还能点着换。
- 展现形式的真实用法细分到 46 类：纸本拆成书信、日记手账、表单票据、档案报告、病历体检、试卷作业、契约协议；书册拆成小说读物、相册图鉴、漫画绘本、词典百科、诗词文学；设备、游戏、画面、音像、公告也各自细分。关键词只用两个字以上的词，避免误判；个别看不出媒介的形式直接指定所属类别。
- 新增「智绘姬」生图渠道：镜面生图里可以选择柏宝绘或智绘姬。选智绘姬时，通过酒馆事件把提示词交给智绘姬，按请求编号接回图片，沿用智绘姬里已经配好的模型、接口和出图设置，不修改它的全局设置。需要先在智绘姬里打开总开关；智绘姬画失败或取消时，会把它给出的原因显示出来。图片会保存成酒馆本地路径；生成成功但保存失败时会明确提示，不会自动重发。
- 内置生图支持一面多张：画面不止一幅时（比如分镜每格），每幅各放一个图框、各画一张；设置了生图 LLM API 时，每张都按自己那一格的画面线索来写提示词。
- 内置生图失败后，图框里会出现「重新生图」，点击时再画一次，不会自动重试。
- 「成人视频网站」改名为「虚构影音站」，并去掉了条目里的真实网站名；「官能色情」改名为「官能描写」，减少模型因为字面直接拒答。
- 镜面生图新增「生图 LLM API」。设置后，手动生图和内置生图的提示词都由它来写；不设置时，手动生图由副 API 单独请求一次，内置生图的提示词在生成小剧场时由副 API 一并写好，不另外请求。
- 新增小剧场内置生图：感谢@nancyindaeyo做的新功能。设置里「启用小剧场内置生图」，默认关闭。开启后，只有这一面本来会用色块或 SVG 画人物、场景时，才改成一个图框；生成结束后自动调用一次柏宝绘把图画进框里。

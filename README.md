## 2.84.0 副 API 读得更准：手动加世界书、按原文读正文、换宏

**世界书**

- 设置 →「它可以参考什么」→「更多：从全部世界书里加书」：先点「拉取全部世界书」，这个聊天没用到的书勾上就加进来，对所有聊天、所有角色都生效，这一轮酒馆没触发也读——常驻条目每次都带，别的条目看最近几楼正文里有没有它的关键词。最多 12 本，要开着「读取本轮已激活的世界书」。以前这里勾上没用，只能关掉书。
- 加进来的书列在「当前聊天相关世界书」里，标「手动加的」，取消勾选就移出。以前关掉的书在这里勾上只是恢复，不会加进所有聊天。
- 世界书一共有字数上限（酒馆触发的和手动加的一起算），超了会截。

**正文怎么读**

- 「读取范围」多了「正文怎么读」：默认照旧读页面上看得见的字；选「原文」就读消息原文——套酒馆发给正文模型时的正则，去掉标签留下字，没渲染出来的楼也读。状态栏、思考这类用标签包着的，到「正文标签过滤」里设成跳过，就不会带上。
- 酒馆里隐藏了的楼（眼睛按钮、/hide）不再读进去。

**宏**

- 角色卡、Persona、世界书里写的宏（{{getvar::…}}、{{random::…}}、{{time}} 这些），发出去之前交给酒馆换成值；会改变量的宏（{{setvar}} 这类）不再执行一遍，直接去掉。没写宏的，发出去的和以前一样。

**记忆插件和生图**

- 副 API 也读勾选的记忆插件（柏宝书等）：抽到「共同回忆」时，以前副 API 下只读千千结。
- 生图也读柏宝书的人物档案：主角、NPC 的外貌和这一楼时的衣着、性别。

**闪退自查**

- 每次没了的记录多写两样：网页字体一共下了多大，页面上的内嵌页面有几个是兔子镜的、别的插件的那些有多大。平时用起来什么都不变。

## 2.83.6 天时认得出更多状态栏的写法

- 状态栏里写「时刻：巳时三刻」的（有的预设的状态栏就这么写），以前天时读不到时辰，标题栏的样子不跟着时间走；现在认得出。「当前时间」「当前时刻」「钟点」「当前日期」「当前天气」「天候」「当前地点」也一样。

## 2.83.1 交互后才露出来的插图不再停住

- 点开才看得到的插图（解锁后的相册、翻开的内页这类）：点空白回到开头、维修兔修过这一面以后，正在画的图不再停在「正在生图」，画好的图也不会不见，不用再点进去才出来。
- 在插图面板里重画、换过版本的图，点空白回到开头以后不再退回旧的那张；图框比例也会跟着图重新调好。回到开头以后面上的字体不会再过一会儿变回系统字体。
- 「打不开？看提示」只出现在真要密码的锁上（按一串数字、单字的密码键，几个转盘一起对的转轮锁）；照顺序一个个解锁的、单独一个转盘不再出现，样子也淡了一些。面被换回开头以后它照样点得开。

## 2.83.0 要密码的锁打不开？看提示

- 面里要按对密码、转对格子才解得开的锁：面上没写提示、或者写的提示和密码对不上时，锁下面会多一颗「🐰 打不开？看提示」，点开就看到该怎么按。不点不剧透，面上本来就写着密码的不加（转盘锁一律加）。
- 生成失败时可以点点卡上的兔子。

## 2.79.8 这一轮更新了什么

**出问题了，点这里**

- 「工具」里多了一项「出问题了，点这里」：点一下是哪种情况（没生成出来、按了没反应、以前的兔子镜不见了、回复下面没有框、页面突然刷新、手机卡），维修兔告诉你先做什么、带你去对的那一页，再给一段能直接复制给作者的字。这段字只有版本、设备、设置和几个数字，不含聊天内容。
- 「工具」里多了一项「页面突然刷新了」：列出这台设备最近几次页面突然没了之前在做什么，量一下这个聊天文件多大、兔子镜占多少，看得出原因的会说一句能做什么。只看本机记下的数字，不联网。

**📮 发给作者**

- 工具里各处报告（存档清单、闪退自查、卡顿自查、手动生成记录、「旧镜面待恢复」的记录、外部诊断、最近几面体检、生成内容取证，还有上面那段）旁边多了「📮 发给作者」：点了出一个小窗，可以直接发送，也可以先写几句备注；点「看看会发什么」能看到要发的原样内容。
- 这些不会自动发，只有你自己点了才发。发之前网址、人名、聊天名、本机路径里的用户名都换成代号，模型名只留本名；生成内容取证发的是打码版，聊天内容和模型写的字都换成占位。

**手机上画图**

- 手机上一面里有好几张图时，改成一张一张画（前一张回来再画下一张），少一些画图时页面突然刷新。电脑上照旧。

**更新、回退**

- 更新失败时按原因分开说（连不上 GitHub、留下了锁、装的版本没了、文件没写完整……），不再都是同一句「可能是本地改动，也可能连不上 GitHub」。酒馆的原话折叠在下面，旁边也有「📮 发给作者」。
- 更新时报「'shallow' file could not be locked」、过一会儿再点还是一样：是上一次更新到一半酒馆被关掉了，留下了一把锁，只能删掉重装。现在这句提示里写上了重装要填的地址和分支。
- 更新窗口最上面写明你装的是测试版还是正式版，旁边能换。删掉重装时没填分支、悄悄从测试版变成了正式版，会提醒一次，点一下就能换回去。
- 点「确认更新」后只说「酒馆说已经是最新」、等多久再点都是这句：有时新版本的文件其实已经装好了，只是页面用的还是旧的。现在会认出来，直接刷新页面换上。
- 更新、换版本刷新以后会说一声「已经更新到某某版」；还是旧的，直接说要把 TT 从后台划掉再打开（网页版是关掉网页再打开）。
- 打开「回退版本」时，版本列表直接从 GitHub 读（电脑版酒馆以前一打开就要先下载约 200 MB）。
- 在 TT 上不再出现只有电脑版酒馆才会有的说法（「本地扩展目录有改动」这类）。

**新玩法**

# 兔子镜酒馆助手接口 v1

本地候选版：1.6.4-api.2。基于 2026-09-22 下载的 toto/main（上游 manifest 为 1.6、入口缓存标记为 1.6.3）。尚未推送官方仓库。

用途：让第三方酒馆助手脚本复用兔子镜里已经保存的副 API 与所选记忆。无需再次填写 Key。入口为酒馆主窗口的 `window.RabbitMirrorAPI`，接口版本为 `1.0.0`。

这是浏览器同源 JavaScript 接口，不是公网 HTTP 服务。脚本 iframe 可通过同源父窗口取得接口，跨域/不允许同源的沙箱不能访问。参见随包 `tavern-helper-example.js` 的取得接口函数（会检查父窗口并最多等待 5 秒）。同源脚本属于可信代码；不返回 Key 不等于对恶意同源代码提供权限沙箱。

## 最常用的调用

```js
const api = await getRabbitMirrorAPI(); // 复制随包示例里的函数
const settings = api.connection.getSettings(); // 不含 Key，只有 hasApiKey
const memory = await api.memory.read();
// memory = { enabled, text, sources, errorCount }

// 请绑到用户点击事件。会使用已配置的副 API，可能计费。
const result = await api.generate({
  prompt: '根据记忆写一段简短问候。',
  systemPrompt: '用中文回答。',
  includeMemory: true,
});
// result.text 由调用脚本展示；不要用不可信 innerHTML 执行模型输出。
// 不自动写聊天、不覆盖既有镜面、不替脚本选择展示位置。
```

`generate` 是文本调用，不会自动抽取兔子镜母本、生成/重说某个已有镜面，或自动读取聊天、角色卡与世界书全库。`prompt` 是调用者本次提供的正文。为兼容已有安全传输，内部添加明确注明“仅脚本输入”的边界，不代表真实楼层。副 API 中的模型、温度、输出长度和高级参数沿用现有配置。若需要兔子镜某种内容格式，由脚本明确提供提示词。

`includeMemory` 默认为 false；为 true 时，只读取用户当前选中的记忆来源和绑定记忆世界书，再随本次请求发送。记忆总开关关闭时不读取；未选择来源时返回空内容。若任一来源读取失败，生成停止，不悄悄带着部分资料继续计费。`memory.read()` 则返回可读部分及 `errorCount`，由脚本决定如何展示缺口。

## 方法

| 方法 | 用途 |
| --- | --- |
| `getStatus()` | 接口版本、脚本请求 busy 状态、能力清单；不代表模型连通性 |
| `connection.getSettings()` | 读取副 API 设置副本，不返回 Key |
| `connection.updateSettings(patch)` | 部分更新、校验并调用原插件保存逻辑 |
| `connection.listProfiles()` | 可用的宿主 Connection Manager 配置 `{id,name}`，不含秘密 |
| `connection.listModels()` | 使用当前配置拉取模型；沿用宿主已保存模型回退，因此不等于远端连通测试 |
| `memory.getSettings()` / `updateSettings(patch)` | 读取/部分更新记忆设置 |
| `memory.listProviders()` | 扫描现有可识别记忆插件；只有 `readable` 且 `selectedAllowed` 才建议选择 |
| `memory.listWorldBooks()` | 列出可绑定世界书目录 `{fileId,displayName}`，不读取正文 |
| `memory.read()` | 按当前设置读取记忆，最多 6000 字符，不改原记忆内容 |
| `generate(options)` | 返回 `{text,requestCount}`；每次显式调用最多一次生成传输 |
| `stop()` | 请求停止本接口当前生成；没有请求返回 false |

原记忆适配器当前读取至多前 6 个所选插件来源及 1 本绑定世界书，支持同步 `getInjectedHistory()`；只检测到安装痕迹、或仅提供异步历史接口的插件可能不可读。本接口没有新增通用“写入/删除记忆正文”功能。手动脚本读取包含用户选中的插件来源，不改变原小剧场自动生成的记忆读取策略。

## 可写设置

字段名与原插件一致；未列出的字段拒绝。传入无效字段时整批不写入。设置 API 不切换原小剧场的跟随/独立生成模式，不自动开启生成。

副 API：

- `independentConnectionProfileId`（字符串，160 字符以内）。优先使用宿主配置；选择它会按原设置逻辑清除手动 Key。
- `independentApiBaseUrl`（空串或 HTTP(S) URL，禁止用户名/密码、查询参数、fragment）；`independentApiModel`（200 字符以内）。
- `independentApiKey`（仅写，4096 字符以内）；读取只得 `hasApiKey`。更换 URL 且已有 Key 时，必须同时给新 Key 或传 `''` 清除旧 Key。Profile 与非空手动 Key 不能同时设置。
- `independentApiTemperature`：0–2；`independentApiMaxTokens`：512–32000 整数。
- `independentMaxRequestChars`：8000–2000000 整数；既有传输仍另有 192 KiB 请求限制。
- `independentContextMaxLayers`：1–200 整数；`independentContextExcludedTags`：最多 32 个字符串，每个 100 字符以内。
- `independentReadCharacterCardSummary`、`independentReadPersonaSummary`：布尔。以上上下文设置供原小剧场生成使用；脚本文本调用不会自动读取它们。

记忆：

- `memoryScanEnabled`、`memoryWorldBookEnabled`：布尔。
- `memoryWorldBookId`：使用 `listWorldBooks()` 的 `fileId`，空串取消绑定。
- `memoryProviderIds`：使用扫描返回的 id，最多 12 项，按原插件逻辑去重（实际读取前 6 项）。
- `memoryMaxChars`：600–6000 整数。

```js
api.memory.updateSettings({ memoryScanEnabled: true, memoryMaxChars: 3000 });
// 仅在用户在脚本设置中主动选择来源后：
api.memory.updateSettings({ memoryWorldBookEnabled: true, memoryWorldBookId: selectedFileId });
```

这些更新使用原宿主的延迟保存方法；返回表示内存设置已应用、保存已排队，不是磁盘保存回执。已打开的兔子镜设置面板可能需要关闭再打开才能显示新值。事件 `rabbitmirror:api-settings-changed` 的 detail 仅包含 `{section,keys}`，不含设置值或 Key。

## 停止、错误与生命周期

`timeoutMs` 默认 120000，范围 1000–300000。`manualRetry: true` 仅用于用户明确手动重试时，采用原副 API 可能暂存的非流式等兼容配置；不会自动追加第二次请求。不要在失败后写无限重试。

本接口只允许一个脚本生成请求；进行中不能通过本接口修改设置。`stop()`/超时会终止等待并发出 AbortSignal，但宿主或上游可能已开始计费。若宿主忽略取消，busy 会保留到传输结束，防止立即发重复请求。原小剧场自身的生成不属于这个脚本 busy 锁。

错误对象带稳定 `code`：`UNAVAILABLE`、`INVALID_ARGUMENT`、`KEY_REQUIRED`、`BUSY`、`NOT_CONFIGURED`、`SETTINGS_CHANGED`、`REQUEST_TOO_LARGE`、`MEMORY_UNAVAILABLE`、`HOST_ERROR`、`UPSTREAM_ERROR`、`REQUEST_FAILED`、`ABORTED`。不回传原上游错误正文/请求头。不要把 `errorCount === 0` 或 HTTP 200 当作记忆完整性证明。

为保持现有边界校验，prompt/systemPrompt/附带记忆不得包含 `【当前聊天逐轮正文…`、`【当前角色卡…`、`【当前世界书、作者注释与实际扩展提示…` 或 `<兔子镜近输出短锁` / `</兔子镜近输出短锁` 保留片段；遇到返回 `INVALID_ARGUMENT`，请只传内容正文。

插件停用会撤销入口并停止接口请求；旧引用报 `UNAVAILABLE`，再次启用/刷新后重新取得接口。宿主窗口发 `rabbitmirror:api-ready`，不保证脚本监听时还没错过，优先先检查入口。

## 安装与验证范围

备份现有兔子镜文件。完整 ZIP 的 `RabbitMirror/` **内部内容**覆盖既有兔子镜扩展目录，不额外嵌套文件夹；也不要与另一份兔子镜同时启用。完整刷新酒馆，扩展版本应为 `1.6.4-api.2`，接口版本应为 `1.0.0`。无需清理站点数据、聊天、母本或成品。可用原文件备份回滚。官方仓库后续更新可能覆盖本地候选功能，正式合并前请保留此包。

`docs/` 是对接文档、类型和示例，`tests/` 为开发测试，均不会被插件自动执行。示例导入本身不发请求；按需复制函数或自行提供可访问的模块 URL。

已执行本地契约与适配器测试，使用真实设置模块、真实记忆读取模块和真实安全边界校验，模型传输替身模拟返回。没有在用户在线酒馆安装，没有调用真实付费模型；实际酒馆助手 iframe、云宿主、手机与供应商仍需安装后验收。

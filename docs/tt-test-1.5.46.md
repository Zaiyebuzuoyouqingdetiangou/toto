# 1.5.46 TT 专项测试说明

这不是通用正式版，也不是所有 TT DOM 虚化问题的最终修复。仅源码/自动化验证，尚未真机验证。

## 本次调整

- TT 入口先同步登记 ChatSurface，再异步加载原核心；登记前不再等待核心的静态模块依赖。
- TT 设置入口与聊天挂载分开：注册失败、普通静态模式或未检测到聊天接口时，仍显示轻量设置入口。点击后按需加载完整设置，不触发生成。
- 补齐入口停用、核心迟到、旧安装被替换时的隔离；不会因打开设置补注册或重发生成请求。
- 更正晚注册提示：只能确认“尝试登记时窗口已关闭”，不能只凭此断言是 TT 文件加载晚了。

没有改写 Prompt、母本、历史结果、美化/维修功能或付费请求限制；未增加常驻轮询、全库扫描或备用剧场面板。1.5.45 正式包不变。

## 安装到 tt 测试分支

先备份当前插件文件和酒馆数据。将本 ZIP 解压后，上传 RabbitMirror 文件夹内的内容到 tt 分支仓库根目录，根目录应直接看到 manifest.json、tt-entry.js、index.js、src 和 data，不要上传成多套嵌套目录。

在 TT 更新同一份兔子镜安装后，彻底退出并重启 TT。保持原有 DOM 虚化开关测试；不要同时启用正式版、测试版两个副本。这个 ZIP 不会替你创建、推送或切换远端分支，auto_update=false，避免未经确认自动更新。

## 真机验收顺序

1. 先只启动 TT、打开扩展设置：应看到“兔子镜小剧场 · TT 测试”或兔子镜设置入口。
2. 点击“打开设置与诊断”：应能展开；失败应有明确提示，而非整块消失。
3. 保持 DOM 虚化，打开已有聊天、上下滚动到已有小剧场，检查可见性和展开。此步骤不需要发生成请求。
4. 运行一次 TT 诊断，查看 managed、registered、registrationFailure 以及挂载记录。registered=true 只说明登记成功，不代表所有展示/交互都已通过。
5. 如仍显示 late-projection，说明这个设备上入口执行前注册窗口就已关闭；本补丁没有重新打开窗口的能力，请保留诊断反馈。不要靠重复点击生成测试登记。

当前自动化覆盖：真实 ESM 入口与受控 TT 接口的提前/迟到登记、lease 回放、设置失败/取消、单次拦截器转发及旧实例隔离。浏览器宿主接口和最终模型传输为本地替身，不等于 TT 真机验收。完整旧单测仍有 45 个失败；本次对照未新增失败名称，不代表旧失败已经修复。

需要回退时，恢复已备份的旧插件文件并重启；不要删除生成历史或母本库。

# 1.6.4-api.5 创作模式

基于 main 的交付分支继续增加创作选项，保留 api.3 / api.4 的抽取校验、重说保存和失败面重试修复。更新后完整刷新页面；已有镜面、收藏与图片不重建。

## 使用

- 每面呈现方式新增“长文本 · 3000–5000 字”。默认空白小剧场，按人物与上下文写作，不抽主题或展现形式、不套视觉美化。也可选“常规抽取”或“只抽已启用的独立文本条目”。原条目／本轮点菜的明确字数和 HTML 要求优先，正文可穿插所需 HTML。所有面仍共用原有输出额度，模型截断时不能保证达到目标字数。
- 创作补充词下方增加“文风”，保存后作用于跟随与独立模式；清空只影响后续生成。文风不覆盖人物事实、原条目篇幅或 HTML 要求。
- 独立 API 世界书设置新增“自动参考当前角色主世界书”。只读当前角色绑定的主世界书，无绑定时才用卡内世界书；仅纳入已启用条目，并遵守本插件停用书名单。它们是人物／故事背景，不加入随机题库，也不额外执行关键词触发。读取材料上限 8000 字符并受完整请求预算约束；超限有截断标记。切角色、换绑定或关闭选项会阻止旧准备任务继续发送。附加绑定书不在本次范围内。
- 生图设置和单面生图面板新增“形式落地／长文高光”。有可信形式记录时参考该形式与成品构图；长文本选择正文中真实发生的高光。无记录时只依据成品内容，不凭标题补造形式。切换构图选项仅影响重新构思，保留现有提示词草稿。
- 内置展现形式新增“印象之匣”（5.1.1.7）与“画给你的自由插画”（2.1.7.2），要求模型用安全 HTML/CSS/SVG 实际绘画，随人物和语境构图，没有预设画稿。不放开执行生成脚本。
- 外置库管理显示当前可抽的主题／形式／文本数量，明确区分库内总数与启用候选数。显式“文本／纯文本／长文本”分类可被识别。

## 抽取与兼容边界

原“文本”模式优先抽文本类；如果该类只有五个睡眠报告，其他分类的条目不会参与。这不是证明用户现场随机实现损坏。隔离复现使用五个文本与九十五个形式条目，文本模式的 100 次抽取均来自五个文本；自动模式可以抽到其他形式。

本次保留既有库权重及按条目防重复规则，没有新增语义题材去重。希望混合题材可用长文本的“常规抽取”，或扩大文本类候选。选择“只抽文本”但没有候选时明确提示，不静默替换来源。

空白长文本的空编号记录会完整保存，可用于单面／多面重说。已有点菜内容不额外写入历史元数据；缺少原点菜素材时仍不伪称可以精确复现原配方。失败面的手动重试行为保留。

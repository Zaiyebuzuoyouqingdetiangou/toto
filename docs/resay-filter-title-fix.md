# 1.6.4-api.3：重说恢复、过滤提示与标题修复

## 修复内容

- 独立镜面的读取及局部同步，在相同消息、Swipe、来源校验通过后比较成品时间，选择较新的本地／聊天元数据副本，避免旧副本覆盖重说结果。删除标记仍优先，不恢复其他来源的内容。
- 多面重说成功原位替换后清除忙碌状态；已结束的任务不再由同步重新标为正在重说。普通版本恢复仍保留尚未完成请求的忙碌状态，邻面内容不变。
- 旧标题的浮动工具布局不再覆盖兔子镜自有标题的弹性布局，修正桌面展开箭头显示为竖线的问题。
- 原条目取消勾选／停用等情况，重说提示具体原因和恢复方式；原面记录缺失、不完整和自定义点菜无法还原也分别提示。不会偷偷换成另一条目或放开已禁用条目。

只保留一条可用文本或展现条目时，单面新抽取可以工作；要求两面不同随机展现时，一条候选仍不足。重说保留原选题，需要原条目可用。本次不改变抽签比例、提示词、模型请求数量或过滤规则。

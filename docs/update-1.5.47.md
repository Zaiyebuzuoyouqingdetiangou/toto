# 1.5.47 TT 测试说明

## 怎么使用

- 文件导入：设置首页 → 母本库：导入与备份 → 导入文件 → **选择 TXT / MD / JSON 文件**。读取后确认分类并保存，再启用库与「外部母本参与抽签」。读取文件本身不保存或发送内容。
- TXT / MD 每个文件作为一个条目，不要求先转 JSON。兼容 UTF-8、带 BOM 的 UTF-16 LE/BE；不猜测无标记的 GBK 等编码。损坏或不支持的文件请另存为 UTF-8。没有用户失败文件，不能确认所有反馈都是编码问题。
- TT 轻量设置入口可点击「查看已有小剧场」；完整设置入口在「工具与维护」的 **TT：查看已有小剧场**。
- 面板每页查看当前聊天的 20 楼，点某楼后才预览，显示该楼当前回复中的兔子镜或聊天元数据中已保存的独立结果。未找到不代表已删除；旧版仅在本机缓存里的独立结果暂不可读，不会自动迁移。
- 独立查看不运行脚本、维修补丁、外部链接或外部媒体，原生折叠和部分 CSS 交互可用。不同源版本会明确提示，面板不会把旧成品改绑到新正文。关闭或切换聊天会清理面板。

## TT 的真实边界

1.5.46 真机报告明确为 managed=true / registered=false / late-projection。轻量登记入口已执行，但 TT 首次聊天投影已关闭登记窗口；当前公开接口没有本页补登记方法。不能通过重试、强制开关或私有 DOM 接管把它说成已修复。

本版仅增加另一种已有内容查看方式，不修复原位置内嵌，也不在面板中生成新作品。不关闭 DOM 虚化、不扩大历史加载、不新增常驻轮询或 Observer。云酒馆不显示 TT 面板入口。

## 外部母本反馈

离线原创夹具核查未发现高级排参删除外部母本：真实选材/Prompt/适配器路径的 50 次替身请求均保留选中材料。这不是 Gemini 真正采用材料的证明，没有调用真实模型。

确认的诊断问题是多面摘要原先只列第一面。现在逐面显示内置/外部数量；缺字段显示未知。仍不会把「抽中」说成「已发送」或「模型采用」。强制动态视觉以及对应类型没有可用外部条目时的既有回退规则没有修改。

## 验证与安装

仅源码/离线自动化验证，尚未 TT/iPhone 真机验证。旧包、历史、母本、Prompt 与单目标一次请求限制保留。安装包不含开发 tests、scripts、package.json；开发源保留它们，打包前重建并校验母本索引。

本包用于 toto 的 tt-test 分支；解压后上传 RabbitMirror 文件夹里面的内容，manifest.json 与 tt-entry.js 应位于仓库根目录。不要覆盖 main，也不要同时启用两份。重启后核对 1.5.47；本地 ZIP 交付不等于已上传。

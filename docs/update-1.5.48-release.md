# 1.5.48 正式版：与 TT 测试通道分离

这份包给 main 正式分支使用，保留 1.5.48 外部母本修复和既有功能。TT 测试包另行保留，不覆盖、不删除。

## 本次仅移除

- 扩展列表里额外出现的 TT 备用设置栏及“打开设置与诊断”动作。
- “独立查看已有小剧场”按钮、加载入口、面板及其运行模块。
- 只为该 TT 备用栏服务的生成式 tt-entry 启动文件；正式版走原正常 index 入口。

不是把按钮藏起来；相关独立模块不在正式 ZIP 内。正常“兔子镜小剧场”设置、高级设置、原有诊断、跟随/独立生成、母本管理、复制 HTML、维修兔和挨打猫继续保留。

## 保留 1.5.48 的两条实际修复

1. 导入、启用或停用外部库/条目后，新生成不再沿用过期的部分点菜随机缓存；当前进行中的生成仍冻结选材。
2. 自动摘要优先正文，避免长标题和关键词把内容挤掉。旧库符合旧算法的已选摘要仅修正本次发送副本，不要求重新导入、不修改原文或历史成品。

不提高抽取比例，不改 Prompt 预算，不新增诊断入口、后台扫描或付费请求。原失败不自动重试；这些修复不保证每个模型都遵从外部材料。

## 安装与分支

上传 GitHub 时选择 main，上传 ZIP 内 RabbitMirror 文件夹里面的文件和子文件夹，不是 ZIP 本身。不要覆盖 tt-test，也不要同时启用两份兔子镜。

若 main 或安装目录曾放过 TT 包，先备份，再仅移除这三个旧程序文件：

- `tt-entry.js`
- `src/ttSettingsEntry.js`
- `src/ttTheaterViewer.js`

本包已经不含这些文件；覆盖上传本身不会删除旧文件。不要清空站点数据、库或聊天。完整刷新或重启宿主，确认 1.5.48；缓存 cohort 为 `1.5.48-release1`。覆盖 ZIP 不会替用户切换宿主记录的安装分支。

TT 专用分支可以独立实验更早登记，但不能仅靠分支保证永不漏注册。本包没有修复 TT late-projection，也没有关闭 DOM 虚化。

## 验证边界

验证正常设置、被删除功能不可达、JS/ESM 缓存闭包、外部母本回归、打包索引与 ZIP 解压一致性。全套历史测试仍有已存在的失败，不能称全绿；完整结果记录在开发工作目录的 verification 中。

仅源码/自动化验证，尚未真机验证；没有真实 TT WebView、Gemini/DeepSeek 或付费模型调用。

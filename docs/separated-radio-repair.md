# 1.6.16-test.7：维修兔的分离式单选卡片修复

当 radio 被包在 label 中，而内容卡片集中放在另一个容器时，模型可能仍写出 `.control:checked + .panel`。这个相邻选择器无法命中，表现为选项能选中但正文不换，维修诊断找不到受控目标。

本版利用已有编号恢复明确的对应关系：同一组 radio 的 value、label 内编号和各卡片标题编号必须唯一且一致，选项区和内容区必须相邻，数量一致，已有 CSS 明确要求选中后显示卡片。卡片可以换序，不按 DOM 顺序猜测对应关系。正常原生交互、编号重复/缺失/冲突、混合组和不明确结构不进入这条修复路线。

修复复用已有跨父层恢复与互斥卡片状态管理，一次只显示选中的卡片，能回到原有默认分支。正文不重写，不调用模型，不重新抽取。没有新增常驻轮询。

同时修复隐藏验证副本的状态重建：副本会复制样式，但不会复制 WeakMap 内的互斥控制器。现在会在副本内重建已识别的控制器，避免有效切换被误报失败；真实页面控件仍不被诊断程序点击或切换。

- 隔离 Edge 浏览器使用真实运行模块，宿主接口仅作本地替身，网络限本机。使用原创夹具以及用户诊断中源码的临时副本；私人源码不收入仓库。
- 36 项检查通过：手机/桌面宽度、按编号配对、卡片乱序、往返切换、重复安装、序列化后重新挂载、原文保留、诊断目标与第二状态、真实控件不变、模糊结构拒绝，以及正常原生规则兼容。
- 修复前同结构的三个控件均找不到目标；修复后各有唯一目标，诊断的未解析规则为零，隐藏副本验证 matched=true。
- 全量 Node 测试 444 项：417 通过、20 个已有失败、7 跳过；没有新增失败。

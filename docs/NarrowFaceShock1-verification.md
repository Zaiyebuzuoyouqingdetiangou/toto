## 实际改动

运行逻辑仅改 src/outputSanitizer.js 和 src/independentApi.js；其他运行文件只有版本/cache token 更新。

- 新增独立手动入口，进入已有维修锁和 chat/message/swipe/source/face 当前性检查。动态模块加载后再次检查同一 live 节点；中途切换即取消。
- 沿用现有普通/TT宿主定位，核对外置宿主与镜面的完整所有权，按结构内容通道同步复测该宿主；不全局刷新其他消息、不重新挂载。
- 保留标题工具浮动收纳；只对当前面自动尺寸的直接内容主体尝试恢复100%宽度。作者明确尺寸、fit-content、浮动、绝对定位、明显左右边距及多个并列主体不强制改写。
- 正文实测必须达到所属内容盒的94%、产生实际增宽且不溢出，否则撤回本次尺寸属性。
- 原live DOM、checkbox/radio值、事件监听、原文及Prompt保持。无源码重建、模型调用、后台循环、启动扫描或新增持久化任务。
- 当前外置宿主若包含多面，共享通道复测可能让同宿主各面的外框自然随之变宽；不会改写其他面的正文作者样式或其他消息宿主。
- 这是当前挂载镜面的显示恢复，不承诺跨设备保存电击效果。重新挂载仍沿用既有自动恢复；原成品与内容不改。

## 验证边界

本轮新测试抽取并执行实际生产函数；DOM、CSSOM、getBoundingClientRect和宿主为显式模拟。它们验证路线、尺寸条件、所有权、失败撤回和无重复动作，**不能证明真实浏览器必然会产生同样布局**。菜单测试执行实际菜单构造/路由与手动动作，模块加载为受控边界。原40项多面登记/Prompt/单请求保护测试继续运行。

当前环境没有可运行的浏览器二进制；未完成真实云酒馆、本地酒馆、iPhone Safari/WebView或TT实机验证，未发送真实模型请求。TT首次注册失败/late-projection属于另一条加载链，本轮没有修改；宿主无法提供当前挂载身份时不会越界修复。

作者明确固定窄尺寸、深层定位或其他复杂压窄不在本次强制拉伸范围。按钮没有实际增宽时会明确显示未确认恢复，可使用已有生成全链路诊断继续定位。
